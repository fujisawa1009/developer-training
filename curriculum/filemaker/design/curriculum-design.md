# FileMaker資格取得カリキュラム 設計書

## 1. 概要

### 目的
FileMaker認定試験（Claris FileMaker Developer Certification）の合格を目標としたカリキュラムを設計・提供する。

### 対象者
- FileMakerを業務で使用している方
- FileMaker開発者として認定資格を取得したい方
- 実務でFileMakerを活用したい方

### 利用資料
| # | 資料種別 | 格納先 | 用途 |
|---|---------|--------|------|
| 1 | 試験範囲PDF | `materials/exam-scope/` | 出題範囲の確認・カリキュラム構成の設計 |
| 2 | 技術PDF | `materials/technical-docs/` | 各レッスンの学習内容・説明の根拠 |
| 3 | 練習問題サンプル | `materials/practice-questions/` | 各レッスンの演習問題・理解度確認 |

---

## 3. カリキュラム全体構成

### 学習フェーズ

```
フェーズ1：基礎理解（レッスン01〜03）
  └─ FileMakerの概念・データベース設計・レイアウト

フェーズ2：開発スキル（レッスン04〜06）
  └─ スクリプト・リレーション・計算式

フェーズ3：実務応用（レッスン07〜09）
  └─ セキュリティ・外部連携・導入運用

フェーズ4：試験対策（レッスン10）
  └─ 模擬試験・弱点補強・直前対策
```

### レッスン一覧

| レッスン | タイトル | 対応試験範囲 | 目安時間 |
|---------|---------|------------|---------|
| Lesson 01 | FileMakerとは / 環境構築 | 基礎概念・製品概要 | 2時間 |
| Lesson 02 | データベース設計 | テーブル・フィールド・データ型 | 3時間 |
| Lesson 03 | レイアウトとUI設計 | レイアウト・オブジェクト・表示設定 | 3時間 |
| Lesson 04 | スクリプト基礎〜応用 | スクリプト・トリガー | 4時間 |
| Lesson 05 | リレーションシップ | リレーション・ポータル・外部キー | 3時間 |
| Lesson 06 | 計算式とフォーミュラ | 計算フィールド・関数 | 3時間 |
| Lesson 07 | セキュリティ設計 | 権限セット・アカウント管理 | 2時間 |
| Lesson 08 | 外部連携・API | FileMaker Data API・Web連携 | 3時間 |
| Lesson 09 | 導入・運用・最適化 | FileMaker Server・デプロイ | 2時間 |
| Lesson 10 | 試験対策・模擬試験 | 全範囲総復習 | 4時間 |

**合計学習時間目安：約29時間**

## 4. 各レッスンの構成テンプレート

各レッスンは以下の構成で作成する。

```
lessons/lesson-XX-[topic]/
├── lesson.md           # レッスン本文（説明・学習内容）
├── exercises.md        # 演習問題（練習問題サンプルより抽出）
└── summary.md          # まとめ・チェックリスト
```

### lesson.md の構成

```markdown
# Lesson XX: [タイトル]

## 学習目標
- 〇〇を理解できる
- 〇〇を実装できる

## 対応する試験範囲
（試験範囲PDFより該当箇所を記載）

## 1. [セクション名]
（技術PDFの内容を元に解説）

## 2. [セクション名]
...

## 重要ポイント
試験に出やすいポイントをまとめる

## 次のレッスンへ
```

### exercises.md の構成

```markdown
# Lesson XX: 演習問題

## 基本問題（5問）
（練習問題サンプルより基礎的な問題を選定）

## 応用問題（3問）
（練習問題サンプルより応用的な問題を選定）

## 解答・解説
```

## 5. 設計書作成の手順

### Step 1: 資料の格納
1. `materials/exam-scope/` に試験範囲PDFを配置
2. `materials/technical-docs/` に技術PDFを配置
3. `materials/practice-questions/` に練習問題を配置

### Step 2: 試験範囲の分析
1. 試験範囲PDFを読み込み、出題カテゴリを洗い出す
2. 各カテゴリの配点・重要度を確認する
3. カリキュラムのレッスン構成に対応づける

### Step 3: 技術内容のマッピング
1. 技術PDFの章立てを確認する
2. 各レッスンに対応する技術PDF箇所を特定する
3. レッスンごとの学習範囲を確定する

### Step 4: 練習問題の分類
1. 練習問題サンプルを各レッスンに対応づける
2. 難易度別に分類する（基本・応用）
3. 各レッスンの演習問題として組み込む

### Step 5: レッスン作成
1. 各レッスンのフォルダを作成する
2. `lesson.md`（本文）を技術PDFを元に作成する
3. `exercises.md`（演習問題）を練習問題サンプルを元に作成する
4. `summary.md`（まとめ）を作成する

```
    ↓
[レビュー・修正]
    ↓
[完成]
```

## 7. 品質基準

### レッスン品質チェックリスト
- [ ] 学習目標が明確に記載されている
- [ ] 試験範囲との対応が明示されている
- [ ] 技術PDFの内容を正確に反映している
- [ ] 演習問題は本番試験の形式に準拠している
- [ ] まとめに試験頻出ポイントが含まれている

### 難易度基準
| レベル | 説明 | 演習問題の割合 |
|--------|------|--------------|
| 基本 | 試験の基礎概念問題 | 60% |
| 応用 | 実装・設計の応用問題 | 40% |

## 8. 次のアクション

資料を格納した後、以下の順序でカリキュラムを作成します：

1. **資料格納**：3種類のPDFを各フォルダに配置
2. **内容分析**：AIが資料を読み込み、レッスン構成を最適化
3. **レッスン作成**：Lesson 01から順に作成
4. **レビュー**：内容の正確性・試験対応の確認
