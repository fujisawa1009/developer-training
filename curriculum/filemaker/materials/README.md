# 参考資料フォルダ

カリキュラム作成の元となる3種類の資料を格納してください。

## フォルダ構成

```
materials/
├── exam-scope/           # 試験範囲PDF
│   └── *.pdf             # FileMaker資格試験の出題範囲・試験概要
│
├── technical-docs/       # 技術ドキュメントPDF
│   └── *.pdf             # 試験範囲の学習内容が全て記載された技術資料
│
└── practice-questions/   # 練習問題サンプル
    └── *.pdf / *.xlsx    # 実際の試験に準じた練習問題
```

## 格納ルール

| フォルダ | 格納するもの | 例 |
|----------|------------|-----|
| `exam-scope/` | 試験の出題範囲、試験概要、受験ガイド | FileMaker試験ガイド.pdf |
| `technical-docs/` | 公式ヘルプ、技術リファレンス、学習教材 | FileMaker技術資料.pdf |
| `practice-questions/` | 模擬試験問題、サンプル問題集 | 練習問題サンプル.pdf |

## 注意事項

- PDFファイルはそのまま格納してください
- ファイル名は日本語・英語どちらでも可
- 複数ファイルがある場合はそのまま追加してください
