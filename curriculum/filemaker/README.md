# FileMaker資格取得カリキュラム

## このフォルダについて

FileMaker認定資格（Claris FileMaker Developer Certification）の取得を目的としたカリキュラムです。

## フォルダ構成

```
filemaker/
├── README.md              # このファイル
├── materials/             # 参考資料（PDFを格納）
│   ├── README.md          # 資料格納ガイド
│   ├── exam-scope/        # ① 試験範囲PDF → ここに配置
│   ├── technical-docs/    # ② 技術PDF → ここに配置
│   └── practice-questions/ # ③ 練習問題 → ここに配置
│
├── design/                # 設計書
│   └── curriculum-design.md  # カリキュラム設計書（詳細はこちら）
│
└── lessons/               # レッスンコンテンツ（作成予定）
    ├── lesson-01-introduction/
    ├── lesson-02-database/
    ├── lesson-03-layout/
    ├── lesson-04-scripts/
    ├── lesson-05-relationships/
    ├── lesson-06-calculations/
    ├── lesson-07-security/
    ├── lesson-08-integration/
    ├── lesson-09-deployment/
    └── lesson-10-exam-prep/
```

## 開始手順

### Step 1: 資料を格納する

| 資料 | 格納先 |
|------|--------|
| 試験範囲PDF | `materials/exam-scope/` |
| 技術PDF（学習内容） | `materials/technical-docs/` |
| 練習問題サンプル | `materials/practice-questions/` |

### Step 2: 設計書を確認する

`design/curriculum-design.md` でカリキュラム全体の構成を確認してください。

### Step 3: レッスン作成を依頼する

資料格納後、AIにレッスン作成を依頼してください。
