# Lesson 05: まとめ・チェックリスト

## 重要ポイント一覧

### [レイアウト設定]（FM24-2.4.3）
- [ ] 設定できる：レイアウト名・メニュー表示・デフォルト表示形式・スクリプトトリガ・リスト形式の枠表示
- [ ] 設定できない：**テーマ**（レイアウトメニューから変更）

### レイアウトパート（FM24-2.4.4）
- [ ] 上部/下部ナビゲーション：スクロールしても固定表示
- [ ] 総計パート：全レコードの合計
- [ ] 小計パート（前部/後部）：グループごとの集計

### ポータル（FM24-2.4.5）
- [ ] ソートは [ポータル設定] または [リレーションシップ編集] で設定
- [ ] フィルタは [ポータル設定] の [フィルタ計算式] で設定

### 条件付き書式（FM24-2.4.8）
- [ ] 複数条件は上から評価（最初に真になった条件が適用）
- [ ] [x日前より少ない] = 今後x日以内の将来日付（過去は対象外）

### テーマとスタイル（FM24-2.4.10）
- [ ] 優先順位：オブジェクト直接設定 > カスタムスタイル > テーマ
- [ ] テーマ使用の利点：パフォーマンス向上・書式の再利用

### 動的値一覧（FM24-2.4.11）
- [ ] [次のテーブルから関連レコードの値のみ含める] でTOを指定
- [ ] 指定するTOはコンテキストから直接リレーションがあるTO

---

## 試験対策メモ

```
[レイアウト設定]でできないこと → テーマの変更

条件付き書式の日付判定
  [x日前より少ない] → 今後x日以内の未来の日付のみ
  過去の日付 → 対象外

動的値一覧のTO指定
  ポータルコンテキストのTOから直接リレーションしているTOを指定
```
