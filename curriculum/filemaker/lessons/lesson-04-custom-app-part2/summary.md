# Lesson 04: まとめ・チェックリスト

## 重要ポイント一覧

### リレーションシップ（FM24-2.3.10・2.3.11）
- [ ] 多対多は中間テーブルで実装する
- [ ] リレーションのソート → 直接配置フィールドは最初の関連レコードの値を表示
- [ ] [レコードの作成を許可] → ポータルから関連レコードを新規作成できる
- [ ] [他テーブルのレコード削除時に連鎖削除] → 親削除で子も自動削除

### 外部データソース（FM24-2.3.12）
- [ ] [外部データソースの管理] で名前・タイプ・所在を管理
- [ ] 外部TOでもリレーション作成・レコード作成設定が可能

### 関数（FM24-2.3.14）
- [ ] `Substitute` + `GetValue` の組み合わせパターンを習得
- [ ] `Let` で変数定義してから計算する構文を理解
- [ ] `Case` の評価順序（上から順番に評価）
- [ ] `IsEmpty` で空値チェック

### カスタム関数（FM24-2.3.15）
- [ ] 作成・管理 → [高度なツールを利用する] が必要
- [ ] 使用（呼び出し）→ 不要
- [ ] 他ファイルからコピー/インポートできる

## 試験対策メモ

```
Substitute + GetValue パターン（頻出）
  @ → ¶ に置換 → GetValue で行番号を取得

リレーションのソート
  直接配置フィールド → 最初の関連レコード
  ポータル → ソート順どおり表示

カスタム関数
  作成 → [高度なツール] 必要
  使用 → [高度なツール] 不要
```
