## 例題 6-1

FileMaker Pro のアクセス権セットについて、適切な記述を**すべて**選択してください。

A. 拡張アクセス権 [fmwebdirect] を許可すると、FileMaker WebDirect でアクセスできるが、[fmapp] を許可しなければ FileMaker Pro からは開けない。

B. [データ入力のみ] アクセス権セットでは、データのエクスポートが許可されている。

C. スクリプトに [完全アクセス権の付与] オプションを設定すると、実行ユーザーのアクセス権に関わらず完全アクセス権でスクリプトが実行される。

D. 拡張アクセス権 [fmxdbc] は、ODBC/JDBC によるアクセスを許可する。

<details>
<summary>解答と解説を見る</summary>

**解答：A, C, D**

**解説：**
- **A（○）**：`fmwebdirect` のみ許可して `fmapp` を許可していない場合、WebDirect からはアクセスできますが、FileMaker Pro（ネットワーク経由）からは開けません。
- **B（×）**：[データ入力のみ] アクセス権セットは、エクスポートが**許可されていません**。デフォルトのアクセス権セットのうち、エクスポートが許可されているのは [フルアクセス] のみです。
- **C（○）**：[完全アクセス権の付与] はスクリプトに設定できる機能で、ユーザーのアクセス権に関わらず管理者権限でスクリプトを実行できます。
- **D（○）**：`fmxdbc` は ODBC/JDBC アクセスを制御する拡張アクセス権です。

**参考：**
- https://help.claris.com/ja/pro-help/content/privilege-sets.html
- https://help.claris.com/ja/pro-help/content/extended-privileges.html

</details>

## 例題 6-2

FileMaker Pro のデータベースファイルの暗号化に関して、適切な記述を**すべて**選択してください。

A. データベースファイルを暗号化するには、[ツール] メニューの [Developer ユーティリティ] を使用する。

B. 暗号化するには [高度なツールを利用する] オプションが選択されている必要がある。

C. 共有 ID に設定する値は大文字と小文字が区別される。

D. 複数のファイルで構成されるカスタム App のすべてのファイルを同じパスワードと共有 ID で暗号化すると、起動時に一度の認証でアクセスできるようになる。

E. オープン格納のオブジェクトフィールドを含むファイルを暗号化すると、そのオブジェクトフィールドは強制的にセキュア格納に変更される。

<details>
<summary>解答と解説を見る</summary>

**解答：A, B, D**

**解説：**
- **A（○）**：[ツール] メニュー → [Developer ユーティリティ] → [データベースの暗号化] で暗号化できます。
- **B（○）**：[Developer ユーティリティ] を使用するには [高度なツールを利用する] が選択されている必要があります。
- **C（×）**：共有 ID は大文字と小文字が**区別されません**（試験頻出の落とし穴）。
- **D（○）**：複数ファイルを同じパスワードと共有 ID で暗号化すると、起動時に何度もパスワード入力が求められなくなります。
- **E（×）**：ファイルを暗号化しても、オープン格納のオブジェクトフィールドが**自動的にセキュア格納に変更されるわけではありません**。格納方法の設定は別途行う必要があります。

**参考：**
- https://help.claris.com/ja/pro-help/content/encrypt-databases.html

</details>

## 例題 7-1

FileMaker Pro でデータをインポートする場合の動作として、適切な記述を**すべて**選択してください。

A. スクリプトトリガ OnRecordCommit は、インポート時にも発動する。

B. 索引が設定されているフィールドへのインポートが完了すると、索引が生成・更新される。

C. 入力値の自動化が設定されているフィールドは、インポート設定で [インポート中にフィールドに対して入力値の自動化オプションを実行] にチェックを入れることで実行できる。

D. [置換] インポートでは、ソースファイルのレコードが現在の対象レコードに順番に上書きされる。

<details>
<summary>解答と解説を見る</summary>

**解答：B, C, D**

**解説：**
- **A（×）**：スクリプトトリガは**インポート時には発動しません**。OnRecordCommit などのトリガはインポート処理では実行されないため、スクリプトトリガに依存した処理はインポート後に手動で実行する必要があります。
- **B（○）**：インポート後、対象フィールドに索引が設定されている場合、索引が生成・更新されます。
- **C（○）**：インポートダイアログに [インポート中にフィールドに対して入力値の自動化オプションを実行] のチェックボックスがあり、これを有効にすることで入力値の自動化が実行されます。
- **D（○）**：[置換] インポートでは、対象レコードの先頭からソースファイルのデータで順番に置き換えます。

**参考：**
- https://help.claris.com/ja/pro-help/content/import-records.html

</details>

## 例題 7-2

[編集] メニューの [フィールド内容のエクスポート] コマンドについて、適切な記述を**すべて**選択してください。

A. テキストフィールドの内容は UTF-16 形式のテキストファイルとして書き出される。

B. エクスポートするファイルを暗号化するオプションがある。

C. FileMaker WebDirect では、Web ブラウザのデフォルトのダウンロード先にエクスポートされる。

D. フォルダを新規作成してその中にエクスポートすることができる。

<details>
<summary>解答と解説を見る</summary>

**解答：A, C, D**

**解説：**
- **A（○）**：テキストフィールドの内容は UTF-16 形式のテキストファイルとして書き出されます。
- **B（×）**：[フィールド内容のエクスポート] には**暗号化オプションはありません**。エクスポートしたファイルを暗号化する機能はないため、注意が必要です。
- **C（○）**：FileMaker WebDirect で [フィールド内容のエクスポート] を実行すると、Webブラウザのデフォルトのダウンロード先に保存されます。
- **D（○）**：エクスポート時に新規フォルダを作成してその中にエクスポートすることができます。

**参考：**
- https://help.claris.com/ja/pro-help/content/export-field-contents.html

</details>

## 例題 8-1

FileMaker WebDirect に関して、適切な記述を**すべて**選択してください。

A. FileMaker WebDirect は表形式のレイアウトをサポートしている。

B. FileMaker WebDirect でアクセスするためには、アクセス権セットで拡張アクセス権 [fmwebdirect] を許可する必要がある。

C. ゲストアカウントに [fmwebdirect] 拡張アクセス権を許可すると、パスワードなしで WebDirect にアクセスできる。

D. FileMaker WebDirect では、すべてのスクリプトステップが FileMaker Pro と同様に動作する。

E. FileMaker WebDirect を使用するには、FileMaker Server または FileMaker Cloud でホストされている必要がある。

<details>
<summary>解答と解説を見る</summary>

**解答：B, C, E**

**解説：**
- **A（×）**：FileMaker WebDirect は**表形式をサポートしていません**（試験頻出）。フォーム形式とリスト形式のみサポートしています。
- **B（○）**：WebDirect でアクセスするには、アクセス権セットの拡張アクセス権で `fmwebdirect` を有効にする必要があります。
- **C（○）**：ゲストアカウントに `fmwebdirect` を許可すると、ユーザーはパスワードなしで WebDirect にアクセスできます。
- **D（×）**：一部のスクリプトステップは WebDirect では動作しません（例：電子メールクライアント経由のメール送信など）。WebDirect の制限を把握した上で設計する必要があります。
- **E（○）**：FileMaker WebDirect は FileMaker Server または FileMaker Cloud でホストされているファイルにのみアクセスできます。

**参考：**
- https://help.claris.com/ja/pro-help/content/filemaker-webdirect.html

</details>

## ポイントまとめ

| 項目 | 重要ポイント |
|------|------------|
| 拡張アクセス権 | fmwebdirect（WebDirect）/ fmapp（FileMaker Pro/Go）/ fmxdbc（ODBC/JDBC） |
| 暗号化の共有ID | 大文字小文字区別**なし** |
| オープン格納とセキュア格納 | 暗号化しても自動変換**されない** |
| スクリプトトリガ | インポート時には**発動しない** |
| [フィールド内容のエクスポート] | 暗号化オプション**なし**、テキストはUTF-16 |
| WebDirect | 表形式**サポートなし**、一部スクリプト制限あり |
