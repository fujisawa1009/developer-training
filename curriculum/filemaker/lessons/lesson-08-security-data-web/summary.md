# Lesson 08: まとめ・チェックリスト

## 重要ポイント一覧

### アクセス権セット（FM24-2.6.1）
- [ ] fmwebdirect：WebDirect でのアクセスを許可
- [ ] fmapp：FileMaker Pro / Go からのネットワークアクセスを許可
- [ ] fmxdbc：ODBC/JDBC によるアクセスを許可
- [ ] fmwebdirect のみ有効 → WebDirect は開けるが FileMaker Pro では**開けない**
- [ ] [データ入力のみ] と [閲覧のみアクセス] はエクスポート**不可**

### ファイルの暗号化（FM24-2.6.2）
- [ ] [ツール] → [Developer ユーティリティ] → [データベースの暗号化]
- [ ] [高度なツールを利用する] が必要
- [ ] 共有ID：大文字小文字区別**なし**（頻出）
- [ ] オープン格納は暗号化しても**セキュア格納に自動変更されない**
- [ ] 複数ファイルを同じパスワード+共有IDで暗号化 → 一度の認証でアクセス可

### [フィールド内容のエクスポート]（FM24-2.7.1）
- [ ] [編集] メニュー → [フィールド内容のエクスポート]
- [ ] テキストフィールドは **UTF-16** 形式
- [ ] 暗号化オプション**なし**
- [ ] WebDirect → ブラウザのデフォルトのダウンロード先にエクスポート

### データのインポート（FM24-2.7.2）
- [ ] インポートの種類：追加 / 更新（既存レコードの更新） / 置換（対象レコードを更新）
- [ ] スクリプトトリガ（OnRecordCommitなど）は**インポート時に発動しない**
- [ ] 入力値の自動化：チェックボックスで制御（有効にすれば実行される）
- [ ] 索引：インポート後に生成・更新される
- [ ] [置換] インポート：対象レコードを先頭から順番に置き換える

### データのエクスポート（FM24-2.7.3）
- [ ] [エクスポートを許可] アクセス権が必要
- [ ] [ファイル] → [レコードのエクスポート]（一括）
- [ ] [編集] → [フィールド内容のエクスポート]（単一フィールド）

### FileMaker WebDirect（FM24-2.8.1）
- [ ] 表形式**サポートなし**（超頻出）
- [ ] FileMaker Server / Cloud でのホストが必要
- [ ] 拡張アクセス権 [fmwebdirect] が必要
- [ ] ゲストアカウントに fmwebdirect → パスワードなしでアクセス可
- [ ] 一部のスクリプトステップは動作しない

## 試験対策メモ

```
アクセス権の落とし穴
  fmwebdirect のみ許可 → FileMaker Pro では開けない（fmapp が必要）
  [データ入力のみ] → エクスポート不可

暗号化の落とし穴
  共有ID → 大文字小文字区別なし
  オープン格納 → 暗号化しても自動でセキュア格納にならない

インポートの落とし穴
  スクリプトトリガ → インポート時には発動しない

エクスポートの落とし穴
  [フィールド内容のエクスポート] → 暗号化オプションなし

WebDirect の落とし穴
  表形式 → サポートなし
  一部スクリプトステップ → 動作しないものがある
```
