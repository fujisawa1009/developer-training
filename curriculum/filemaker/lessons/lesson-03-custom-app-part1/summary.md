# Lesson 03: まとめ・チェックリスト

## 重要ポイント一覧

### 計算フィールド（FM24-2.3.2）
- [ ] [計算結果] でデータタイプをユーザが指定できる
- [ ] 関連フィールドを参照する場合、フィールド値を**保存できない**
- [ ] 索引オプションの有無で再計算タイミングが変わる

### 入力値の自動化（FM24-2.3.4）
- [ ] [作成情報] → レコード作成時のみ記録
- [ ] [修正情報] → レコード更新時に記録
- [ ] [フィールドに既存の値が存在する場合は置き換えない] → 値があれば上書きしない
- [ ] [ルックアップ値] → 参照元からコピー（スナップショット。以後変更されない）
- [ ] [データ入力時の値変更の禁止] → ユーザがブラウズモードで変更できない

### 入力値の制限（FM24-2.3.5）
- [ ] [常時] → スクリプトによる変更も含めて制限
- [ ] [データの入力時のみ] → ユーザの直接入力時のみ制限

### グローバルフィールド（FM24-2.3.6）
- [ ] 全レコードで値を共有する（1フィールド1値）
- [ ] 検索条件に使えない
- [ ] ファイルを閉じると初期値に戻る（共有ファイル）

### 索引（FM24-2.3.7）
- [ ] [必要時に自動設定] → 最初の検索で [最小限] に変わる
- [ ] 関連フィールド参照の計算フィールドは索引設定不可

### オブジェクトデータの格納（FM24-2.3.8）
- [ ] セキュア格納 → 暗号化
- [ ] オープン格納 → ディレクトリ指定可、暗号化なし
- [ ] グローバル格納 + 外部保存 → 自動でセキュア格納
- [ ] 転送結果は Transfer.log で確認

---

## 試験対策メモ

```
計算フィールドの落とし穴
  [計算結果]タイプ → ユーザが指定できる（自動じゃない）
  関連フィールド参照 → 値を保存できない

入力値の自動化の違い
  作成情報 ≠ ユーザ名（環境設定のユーザ名ではなくアカウント名）
  ルックアップ = スナップショット（以後の変更を追わない）

索引の自動設定
  [必要時に自動設定] → 最初の検索実行後に [最小限] に変わる
```
