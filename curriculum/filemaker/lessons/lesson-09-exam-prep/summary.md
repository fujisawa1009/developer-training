# Lesson 09: まとめ・チェックリスト

## 全レッスン重要ポイント 最終確認

### Lesson 01: FileMaker Pro の基礎（5%）
- [ ] 「高度なツールを利用する」でDeveloper ユーティリティが利用可能になる
- [ ] ウインドウスタイル：ドキュメント / フローティング / ダイアログ / カード
- [ ] カードウインドウ：フォーム形式とリスト形式のみ（ポップオーバー不可）

### Lesson 02: レコードの検索とソート（5%）
- [ ] クイック検索：索引フィールドを横断検索
- [ ] 省略の記号：`!`（重複）/ `//`（今日）/ `?`（未入力）
- [ ] 再ソートは [レコード] → [対象レコードを再ソート]

### Lesson 03: カスタム App の作成 前半（25%）
- [ ] グローバルフィールド：レコード非依存、リレーションの結合フィールドとして使用可
- [ ] ルックアップ：コピー後は独立（リアルタイム参照ではない）
- [ ] TO（テーブルオカレンス）：同一テーブルを複数配置可能

### Lesson 04: カスタム App の作成 後半（25%）
- [ ] ExecuteSQL：SELECT のみ / 戻り値は文字列 / 任意テーブルにアクセス可
- [ ] JSON関数：JSONGetElement（取得）/ JSONSetElement（設定）
- [ ] カスタム関数：FileMaker Pro Advanced / Claris Pro でのみ作成可能

### Lesson 05: レイアウトの作成と管理 前半（20%）
- [ ] タイトルヘッダー：印刷時の1ページ目のみ表示
- [ ] 先頭グループ集計：グループの最初のレコードの直前に表示
- [ ] ポップオーバーボタン：ポップオーバーの中にポップオーバーは作れない

### Lesson 06: レイアウトの作成と管理 後半（20%）
- [ ] トリガ実行順序：OnObjectEnter → OnObjectKeystroke → OnLayoutKeystroke → OnObjectValidate → OnRecordCommit
- [ ] OnObjectKeystroke は OnLayoutKeystroke より**先**
- [ ] カスタムメニュー：[環境設定] では設定**不可**

### Lesson 07: スクリプトの利用（20%）
- [ ] While関数：内部変数はWhileスコープのみ（スクリプト変数には影響なし）
- [ ] [ステップイン]：サブスクリプトの中にも入る
- [ ] [ステップアウト]：残りを実行して抜ける（スキップではない）
- [ ] 実行ボタン（▶）：ブレークポイントで一時停止
- [ ] データビューア：変数は値変更可 / フィールドは変更不可

### Lesson 08: セキュリティ・データ統合・Web公開（25%）
- [ ] fmwebdirect のみ許可 → FileMaker Pro では開けない
- [ ] 暗号化の共有ID：大文字小文字区別**なし**
- [ ] オープン格納：暗号化してもセキュア格納に**自動変換されない**
- [ ] スクリプトトリガ：インポート時には**発動しない**
- [ ] [フィールド内容のエクスポート]：暗号化オプション**なし** / UTF-16
- [ ] WebDirect：表形式**サポートなし**
