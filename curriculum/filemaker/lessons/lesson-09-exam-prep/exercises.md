## 第1問

FileMaker Pro のリレーションシップについて、適切な記述を**すべて**選択してください。

A. テーブルオカレンス（TO）は、同一のテーブルをリレーションシップグラフ上に複数配置できる。

B. ルックアップフィールドは、関連レコードの値を常にリアルタイムで参照する。

C. グローバルフィールドは、リレーションシップの結合フィールドとして使用できる。

D. ポータルには、関連テーブルのレコードの一覧を表示できる。

<details>
<summary>解答と解説を見る</summary>

**解答：A, C, D**

**解説：**
- **A（○）**：同一テーブルを複数のTOとして配置可能です。異なる条件での関連付けに使用します。
- **B（×）**：ルックアップフィールドは関連レコードから値を**コピー**します。コピー後は独立しており、元の関連レコードが変わっても自動更新されません（リアルタイム参照は計算フィールドで実現）。
- **C（○）**：グローバルフィールドは結合フィールドとして使用でき、現在のレコードに関わらず一定の値でリレーションを張ることができます（検索などに有効）。
- **D（○）**：ポータルは関連テーブルのレコードを一覧表示するためのレイアウトオブジェクトです。

</details>

## 第2問

FileMaker Pro の集計フィールドについて、適切な記述を**すべて**選択してください。

A. 集計フィールドは、現在の対象レコードセットに基づいて計算される。

B. 集計フィールドの値は、ソートに影響される場合がある。

C. 集計フィールドは、ポータル内で使用するとポータルの関連レコードのみを集計する。

D. 集計フィールドを含む計算フィールドを作成することはできない。

<details>
<summary>解答と解説を見る</summary>

**解答：A, B, C**

**解説：**
- **A（○）**：集計フィールドは対象レコードセット全体を集計します。対象レコードが変わると値も変わります。
- **B（○）**：小計集計（先頭グループ集計・末尾グループ集計）はソート順に依存します。ソートされていないと正しく集計されません。
- **C（○）**：ポータル内の集計フィールドは、そのポータルの関連テーブルのレコードのみを対象に集計します。
- **D（×）**：集計フィールドを含む計算フィールドは作成できます（例：`Sum(テーブル::金額) * 1.1` など）。

</details>

## 第3問

FileMaker Pro の ExecuteSQL 関数について、適切な記述を**すべて**選択してください。

A. ExecuteSQL は SELECT 文のみサポートしており、INSERT や UPDATE は使用できない。

B. ExecuteSQL はリレーションシップに関係なく、任意のテーブルのデータを取得できる。

C. ExecuteSQL の結果はデータ型が文字列として返される。

D. ExecuteSQL は、フィールド名にスペースや予約語が含まれる場合、ダブルクォートで囲む必要がある。

<details>
<summary>解答と解説を見る</summary>

**解答：A, B, C, D**

**解説：**
- **A（○）**：FileMaker の ExecuteSQL は SELECT 文のみをサポートしています。データ変更（INSERT / UPDATE / DELETE）はできません。
- **B（○）**：リレーションシップの設定に関係なく、ファイル内の任意のテーブルに対してクエリを実行できます。
- **C（○）**：ExecuteSQL の戻り値は常に文字列型です。数値として使う場合は型変換が必要です。
- **D（○）**：フィールド名に日本語、スペース、FileMaker SQL の予約語が含まれる場合はダブルクォート（`"`）で囲む必要があります。

</details>

## 第4問

FileMaker Pro のレイアウトパーツについて、適切な記述を**すべて**選択してください。

A. タイトルヘッダーは、プレビューモードおよび印刷時の最初のページのみに表示される。

B. 集計パーツ（先頭グループ集計）は、ソートの基準が同じグループの最初のレコードの直前に表示される。

C. フッターは、すべてのページの下部に表示される。

D. ヘッダーとタイトルヘッダーの両方を設定した場合、すべてのページにタイトルヘッダーが表示される。

<details>
<summary>解答と解説を見る</summary>

**解答：A, B, C**

**解説：**
- **A（○）**：タイトルヘッダーはプレビューモード / 印刷時の**最初のページのみ**に表示され、2ページ目以降はヘッダーが表示されます。
- **B（○）**：先頭グループ集計はソートキーが変わるグループの先頭（直前）に表示されます。
- **C（○）**：フッターはすべてのページの下部に表示されます（タイトルフッターが設定されている場合、最初のページのみタイトルフッターが表示）。
- **D（×）**：タイトルヘッダーは最初のページのみに表示されます。2ページ目以降は通常のヘッダーが表示されます。

</details>

## 第5問

FileMaker Pro のスクリプトトリガについて、適切な記述を**すべて**選択してください。

A. OnObjectKeystroke は、OnLayoutKeystroke より先に実行される。

B. OnRecordCommit は、フィールドの確定時（フォーカス移動時）に発動する。

C. OnLastWindowClose は、ファイルの最後のウインドウを閉じようとするときに発動する。

D. OnObjectModify は、フィールドが確定（コミット）されたときに1回発動する。

<details>
<summary>解答と解説を見る</summary>

**解答：A, C**

**解説：**
- **A（○）**：フィールドへのキー入力時、OnObjectKeystroke が先に実行され、その後 OnLayoutKeystroke が実行されます。
- **B（×）**：OnRecordCommit は**レコードの確定時**（フォーカスがレコード外に移動するとき）に発動します。フィールドの確定時は OnObjectSave が発動します。
- **C（○）**：OnLastWindowClose はファイルの最後のウインドウを閉じようとするときに発動します。ファイルを閉じる処理の前に実行したい処理（保存確認など）に使用します。
- **D（×）**：OnObjectModify はフィールドの値が**変わるたびに**発動します（キー入力ごとなど）。確定時1回は OnObjectSave の動作です。

</details>

## 第6問

FileMaker Pro の変数について、適切な記述を**すべて**選択してください。

A. グローバル変数（$$変数名）は、スクリプトが終了しても値が保持される。

B. ローカル変数（$変数名）は、呼び出したサブスクリプトからも参照できる。

C. Let 関数内で定義した変数は、Let 式の外では参照できない。

D. 変数名の大文字と小文字は区別される。

<details>
<summary>解答と解説を見る</summary>

**解答：A, C**

**解説：**
- **A（○）**：グローバル変数はファイルが開いている間（またはセッション中）値が保持されます。スクリプトが終了しても値は消えません。
- **B（×）**：ローカル変数（$変数名）のスコープは**実行中のスクリプト内のみ**です。サブスクリプトから親スクリプトのローカル変数を参照することはできません。値を渡すにはスクリプト引数またはグローバル変数を使用します。
- **C（○）**：Let 関数内で定義した変数（関数変数）のスコープは Let 式内のみです。
- **D（×）**：変数名は大文字と小文字を**区別しません**（`$Name` と `$name` は同じ変数）。

</details>

FileMaker Pro のスクリプトデバッガについて、適切な記述を**すべて**選択してください。

A. [ステップイン] を使うと、サブスクリプトの中にも入って1ステップずつ実行できる。

B. [ステップオーバー] を使うと、サブスクリプトも1ステップずつ実行される。

C. [ステップアウト] を使うと、現在のスクリプトの残りのステップがすべて実行されてから抜ける。

D. 実行ボタン（▶）をクリックすると、ブレークポイントに関係なくスクリプトが最後まで実行される。

<details>
<summary>解答と解説を見る</summary>

**解答：A, C**

## 第9問

FileMaker Pro のデータベース暗号化について、適切な記述を**すべて**選択してください。

A. [Developer ユーティリティ] でデータベースを暗号化するには、[高度なツールを利用する] が必要である。

B. 暗号化の共有 ID は、大文字と小文字が区別される。

C. オープン格納のオブジェクトフィールドを含むファイルを暗号化すると、セキュア格納に自動的に変更される。

D. マルチファイルの App で、すべてのファイルを同じパスワードと共有 ID で暗号化すると、起動時の認証が簡略化される。

<details>
<summary>解答と解説を見る</summary>

**解答：A, D**

**解説：**
- **A（○）**：Developer ユーティリティを使用するには、FileMaker Pro の [環境設定] で [高度なツールを利用する] を選択している必要があります。

## 第10問

次のスクリプトを実行した後の `$$counter` の値として正しいものを選択してください。

```
変数を設定 [ $$counter ; 値: 0 ]
変数を設定 [ $result ; 値: While (
  [n = 1] ;
  n <= 3 ;
  [n = n + 1 ; $$counter = $$counter + 1] ;
  n
)]
```

A. 0

B. 3

C. 4

D. $$counter は変更されない

<details>
<summary>解答と解説を見る</summary>

**解答：A（D と同じ意味）**

**解説：**

While 関数の**第3引数（処理）内の `$$counter = $$counter + 1`** は、While 関数のローカルスコープ内での変数代入です。

While 関数の内部では `$$counter` という名前のローカル変数を扱っており、**FileMaker のグローバル変数 `$$counter` を変更しているわけではありません**。

While 関数が終了した後、スクリプト側の `$$counter` は Step 1 で設定した **0のまま**です。

`$result` には While の戻り値（最終的な `n` の値 = 4）が入りますが、`$$counter` は 0 のままです。

**重要：** While 関数内での変数操作はすべて While のスコープ内に閉じられており、スクリプト変数（`$` / `$$`）を変更することはできません。

</details>
