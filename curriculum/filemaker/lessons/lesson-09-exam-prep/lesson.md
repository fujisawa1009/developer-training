# Lesson 09: 総復習・模擬試験

## このレッスンについて

CFAD-2（Claris FileMaker 技術者試験 Advanced Developer）の全範囲を振り返り、試験に向けた最終確認を行います。

> **試験情報：** 60分（56分解答）/ 約35問 / 多肢選択式（複数選択あり）

---

## 知識エリア別 重要ポイント総まとめ

### エリア1: FileMaker Pro の基礎（配点 5%）

| ポイント | 内容 |
|---------|------|
| 実行ウインドウのスタイル | ドキュメント / フローティング / ダイアログ / カード |
| カードウインドウ | 親ウインドウを暗くして前面表示。フォーム形式 / リスト形式のみ（ポップオーバーなど不可） |
| ゲストアカウント | ファイルを開くときにパスワードなしでアクセスするための組み込みアカウント |
| 管理者アカウント | 最初から存在する「Admin」アカウント（変更または無効化推奨） |

---

### エリア2: レコードの検索とソート（配点 5%）

| ポイント | 内容 |
|---------|------|
| クイック検索 | レイアウト上の複数フィールドを横断して検索（索引フィールドのみ対象） |
| 省略の検索記号 | `!`（重複）、`//`（今日）、`?`（未入力） |
| 複数基準ソート | 優先順位の高い順に設定。後から追加したフィールドは優先順位が低い |
| 再ソート | 対象レコードへの変更後、[レコード] → [対象レコードを再ソート] で再適用 |

---

### エリア3: カスタム App の作成 前半（配点 25%）

| ポイント | 内容 |
|---------|------|
| グローバルフィールド | レコードに依存しない1つの値（リレーションの検索側に使用可） |
| 集計フィールド | 対象レコードを集計（合計・平均・最大・最小など） |
| テーブルオカレンス（TO） | リレーションシップグラフ上のテーブルの出現。同一テーブルを複数配置可能 |
| リレーション | TOとTO間の関係。結合フィールドが一致するレコードにアクセス |
| ルックアップ | リレーションから値をコピー（コピー後は独立） |

---

### エリア4: カスタム App の作成 後半（配点 25%）

| ポイント | 内容 |
|---------|------|
| ExecuteSQL | SQLのSELECT文を実行してデータを取得（FileMaker SQL構文） |
| Let関数 | 変数を定義して計算式を整理。Let変数のスコープはLet式内のみ |
| JSONGetElement | JSONパスで値を取得。パスは `key` または `[index]` 形式 |
| JSONSetElement | JSONに値を追加・更新 |
| カスタム関数 | FileMaker Pro Advanced / Claris Pro でのみ作成可能。再帰も可能 |

---

### エリア5: レイアウトの作成と管理 前半（配点 20%）

| ポイント | 内容 |
|---------|------|
| パーツの種類 | ヘッダー / ボディ / フッター / 集計パーツ（先頭/末尾）/ タイトルヘッダー・フッター |
| ポップオーバーボタン | クリックで別の入力エリアを表示。ポップオーバーの中にポップオーバーは不可 |
| スライドパネル | 複数パネルを切り替え表示。スライド操作（スワイプ）で移動 |
| フィールドの条件付き書式 | 計算式がTrueのときにフォント・色・スタイルを変更 |
| グラフ | 集計フィールドや各レコードの値をグラフ表示。Webビューアも使用可 |

---

### エリア6: レイアウトの作成と管理 後半（配点 20%）

| ポイント | 内容 |
|---------|------|
| スクリプトトリガ実行順序 | OnObjectEnter → OnObjectKeystroke → OnLayoutKeystroke → OnObjectValidate → OnRecordCommit |
| OnObjectKeystroke | OnLayoutKeystroke より**先に**実行される |
| OnObjectModify | フィールドの値が変わるたびに発動（確定前） |
| カスタムメニュー適用方法 | [カスタムメニューの管理] / [レイアウト設定] / スクリプトステップ（[環境設定] では不可） |

---

### エリア7: スクリプトの利用（配点 20%）

| ポイント | 内容 |
|---------|------|
| ローカル変数 | `$変数名`：スクリプト内のみ |
| グローバル変数 | `$$変数名`：ファイル内全体・スクリプト間をまたぐ |
| While関数 | 内部の変数変更はWhileスコープのみ（スクリプト変数 `$` には影響しない） |
| [ステップイン] | サブスクリプトの中にも入る |
| [ステップオーバー] | サブスクリプトは一括実行（中に入らない） |
| [ステップアウト] | 現在スクリプトの**残りを実行**して抜ける（スキップではない） |
| 実行ボタン（▶） | ブレークポイントで一時停止する |
| データビューア | 変数は値変更可 / フィールドは変更不可（読み取りのみ） |

---

### エリア8: セキュリティ・データ統合・Web公開（配点 25%）

| ポイント | 内容 |
|---------|------|
| fmwebdirect | WebDirect でのアクセスを許可 |
| fmapp | FileMaker Pro / Go のネットワークアクセスを許可 |
| fmxdbc | ODBC/JDBC アクセスを許可 |
| 暗号化の共有ID | 大文字小文字区別**なし** |
| オープン格納の暗号化 | 暗号化してもセキュア格納に**自動変更されない** |
| スクリプトトリガとインポート | インポート時には**発動しない** |
| [フィールド内容のエクスポート] | 暗号化オプション**なし** / テキストはUTF-16 |
| WebDirect | 表形式**サポートなし** / 一部スクリプト制限あり |

---

## 試験頻出の「落とし穴」リスト

```
【セキュリティ】
  × fmwebdirect のみ許可 → FileMaker Pro では開けない
  × 共有ID → 大文字小文字区別なし
  × オープン格納を暗号化 → セキュア格納に自動変換されない

【レイアウト】
  × OnObjectKeystroke は OnLayoutKeystroke より後 → 「先」が正解
  × カスタムメニューは [環境設定] では設定できない

【スクリプト・デバッガ】
  × [ステップイン] はサブスクリプトに「入らない」 → 「入る」が正解
  × [ステップアウト] はスキップ → 「残りを実行して抜ける」が正解
  × 実行ボタン（▶）はブレークポイントで止まらない → 「止まる」が正解
  × データビューアでフィールド値を変更できる → 「変更できない」が正解

【インポート】
  × スクリプトトリガはインポート時に発動する → 「発動しない」が正解

【WebDirect】
  × WebDirect は表形式をサポートしている → 「サポートしていない」が正解
```
