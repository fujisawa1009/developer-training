## データベースとは

データベース（DB）は**データを整理して保存・管理するための仕組み**です。Webアプリケーションのほとんどがデータベースを利用しています。

### なぜデータベースが必要なのか

ファイル（CSV・JSON）にデータを保存する方法と比較してみましょう。

| 観点 | ファイル保存 | データベース |
|------|------------|------------|
| 同時アクセス | 競合が起きやすい | 安全に処理できる |
| 検索速度 | 全件走査が必要 | インデックスで高速 |
| データの整合性 | 保証が難しい | 制約で保証できる |
| 大量データ | メモリに載らない | 効率的に処理できる |

### リレーショナルデータベース（RDB）

このコースで学ぶのは**リレーショナルデータベース**です。データを**テーブル（表）**で管理します。

```
users テーブル
┌────┬──────┬────────────────────┬──────────┐
│ id │ name │ email              │ role     │
├────┼──────┼────────────────────┼──────────┤
│  1 │ 山田 │ yamada@example.com │ admin    │
│  2 │ 田中 │ tanaka@example.com │ learner  │
│  3 │ 佐藤 │ sato@example.com   │ learner  │
└────┴──────┴────────────────────┴──────────┘
```

### 代表的なRDBMS

| RDBMS | 特徴 |
|-------|------|
| PostgreSQL | 高機能・オープンソース。本研修で使用 |
| MySQL | 広く普及・Webアプリに多い |
| SQLite | ファイル1つで動作。モバイルアプリ向き |

> ポイント：このコースではPostgreSQLを使いますが、SQLの基本構文はどのRDBMSでもほぼ共通です
