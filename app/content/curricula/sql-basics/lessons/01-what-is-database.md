## データベースとは

データベース（DB）は**データを整理して保存・管理するための仕組み**です。Webアプリケーションのほとんどがデータベースを利用しています。

### なぜデータベースが必要なのか

ファイル（CSV・JSON）にデータを保存する方法と比較してみましょう。

| 観点 | ファイル保存 | データベース |
|------|------------|------------|
| 同時アクセス | 競合が起きやすい | 安全に処理できる |
| 検索速度 | 全件走査が必要 | インデックスで高速 |
| データの整合性 | 保証が難しい | 制約で保証できる |
| 大量データ | メモリに載らない | 効率的に処理できる |

### リレーショナルデータベース（RDB）

このコースで学ぶのは**リレーショナルデータベース**です。データを**テーブル（表）**で管理します。

```
users テーブル
┌────┬──────┬────────────────────┬──────────┐
│ id │ name │ email              │ role     │
├────┼──────┼────────────────────┼──────────┤
│  1 │ 山田 │ yamada@example.com │ admin    │
│  2 │ 田中 │ tanaka@example.com │ learner  │
│  3 │ 佐藤 │ sato@example.com   │ learner  │
└────┴──────┴────────────────────┴──────────┘
```

### 代表的なRDBMS

| RDBMS | 特徴 |
|-------|------|
| PostgreSQL | 高機能・オープンソース。本研修で使用 |
| MySQL | 広く普及・Webアプリに多い |
| SQLite | ファイル1つで動作。モバイルアプリ向き |

### SQLとは

SQL（Structured Query Language）は、データベースを操作するための言語です。主に以下の4つの操作を行います。

| 操作 | SQL文 | 意味 |
|------|-------|------|
| 作成 | `INSERT` | データを追加する |
| 読取 | `SELECT` | データを取得する |
| 更新 | `UPDATE` | データを変更する |
| 削除 | `DELETE` | データを削除する |

これらをまとめて **CRUD**（Create / Read / Update / Delete）と呼びます。

### PostgreSQL に接続してみる

本研修では Docker で PostgreSQL が動いています。以下のコマンドで接続できます。

```bash
# Docker コンテナ内の psql に接続
docker exec -it <コンテナ名> psql -U postgres -d mydb
```

接続後、以下のコマンドで基本操作ができます。

```sql
-- データベース一覧を表示
\l

-- テーブル一覧を表示
\dt

-- psql を終了
\q
```

> ポイント：このコースではPostgreSQLを使いますが、SQLの基本構文はどのRDBMSでもほぼ共通です

## 練習問題

1. リレーショナルデータベースとNoSQL（MongoDBなど）の違いを調べて、それぞれの特徴を3つずつ挙げてください。
2. 以下の中で、リレーショナルデータベースの特徴として正しいものをすべて選んでください。
   - (a) データをJSON形式で保存する
   - (b) データをテーブル（表）で管理する
   - (c) SQLという言語で操作する
   - (d) 1つのファイルで完結する
3. CRUDの各操作が、どのSQL文に対応するかを書き出してください。
