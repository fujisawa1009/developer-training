## 練習問題 模範解答

### 問題1: リレーショナルDBとNoSQLの違い

**リレーショナルデータベース（RDB）の特徴**
1. データをテーブル（行と列）の形式で管理する
2. SQL（Structured Query Language）でデータを操作する
3. データの整合性をスキーマや制約で厳密に管理する（トランザクション、外部キーなど）

**NoSQL（MongoDBなど）の特徴**
1. データをドキュメント（JSON形式）やキー・バリューなど柔軟な形式で管理する
2. スキーマが固定されておらず、構造の異なるデータを同じコレクションに格納できる
3. 水平スケールアウトが得意で、大量データの高速な読み書きに向いている

### 問題2: リレーショナルデータベースの特徴

正しいもの: **(b) と (c)**

- (a) ❌ JSONではなくテーブル形式で保存する
- (b) ✅ データをテーブル（表）で管理する
- (c) ✅ SQLという言語で操作する
- (d) ❌ 複数のファイル（データファイル、ログファイルなど）で構成される

### 問題3: CRUDとSQL文の対応

| CRUD操作 | SQL文 | 説明 |
|---------|-------|------|
| Create（作成） | `INSERT` | テーブルに新しい行を追加する |
| Read（読み取り） | `SELECT` | テーブルからデータを取得する |
| Update（更新） | `UPDATE` | 既存の行のデータを変更する |
| Delete（削除） | `DELETE` | テーブルから行を削除する |
