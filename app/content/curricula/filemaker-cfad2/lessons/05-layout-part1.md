## 1. デバイスごとの画面設計（FM24-2.4.1）

### デバイス対応の設計ポイント

| 項目 | ポイント |
|------|---------|
| 画面設計 | デバイス（PC/タブレット/スマートフォン）ごとにレイアウトを分ける |
| 画面遷移 | レイアウト間の移動を直感的に設計 |
| 一貫性 | レイアウトテーマ・スタイルを統一して見た目を揃える |
| パフォーマンス | 不要なオブジェクトや複雑な条件付き書式を避ける |

### レイアウトパフォーマンスの最適化

- 表示しないオブジェクトは削除（隠すだけでも計算コストがかかる）
- 条件付き書式は必要最小限に
- 関連フィールドへのアクセスは最小限に

## 2. レイアウト設定（FM24-2.4.2・FM24-2.4.3）

### [レイアウトの管理] ダイアログ

- レイアウトの並び順変更
- レイアウトの表示/非表示（レイアウトポップアップメニューへの表示制御）

### [レイアウト設定] ダイアログで設定できること

| タブ | 設定項目 |
|------|---------|
| 一般 | レイアウト名、レイアウトメニューへの表示 |
| 表示 | [レコードを表示]、[レコードの変更を自動的に保存する]、[アクティブ時にフィールドのフレームを表示]、[現在のレコードのみフィールドに枠を表示]、[現在のレコードインジケータをリスト形式に表示]、[メニューセット]、[クイック検索を有効にする]、[ブラウズまたは検索モードで可能な表示形式] |
| 印刷 | 印刷設定 |
| スクリプトトリガ | レイアウト入退出時のスクリプト |

> **試験頻出：** [レイアウト設定] で設定できることとできないことが出題される。**レイアウトのテーマ**は [レイアウト設定] ではなく**レイアウトメニューから変更**する。

## 3. レイアウトパート（FM24-2.4.4）

### パートの種類と用途

| パート | 表示タイミング | 用途 |
|-------|-------------|------|
| 上部ナビゲーション | 常時（スクロールしても固定） | ナビゲーションボタンなど |
| 下部ナビゲーション | 常時（スクロールしても固定） | 操作ボタンなど |
| タイトルヘッダ | 先頭ページのみ | 表紙タイトル |
| ヘッダ | 全ページ上部 | 列見出しなど |
| ボディ | レコードごと | メインコンテンツ |
| フッタ | 全ページ下部 | ページ番号など |
| タイトルフッタ | 先頭ページのみ | 表紙フッタ |
| 総計（前部/後部） | 全レコードの総計 | 合計値 |
| 小計（前部/後部） | グループの小計 | グループ合計値 |

## 4. ポータル（FM24-2.4.5）

### [ポータル設定] ダイアログの設定

| 設定 | 説明 |
|------|------|
| [ポータルレコードのソート] | ポータル内の関連レコードのソート順 |
| [ポータルレコードのフィルタ] | 表示する関連レコードを計算式でフィルタ |
| [スクロールバーを使用する] | ポータルにスクロールバーを表示 |
| [新規レコードの許可] | ポータルの最後の行から関連レコードを作成 |

### ポータルのソートとリレーションシップのソートの違い

| 設定場所 | 効果 |
|---------|------|
| [ポータル設定] のソート | そのポータルのみに適用 |
| [リレーションシップ編集] のソート | ポータル・直接配置フィールド両方に影響 |

**ポータルのソートが優先** → ポータル設定のソートはリレーションシップ設定のソートを上書きします。

## 5. 動的な表示オブジェクト（FM24-2.4.6）

### レイアウトに挿入できる動的情報

| オブジェクト | 表示内容 |
|-------------|---------|
| 日付 | 現在の日付（印刷時 / 表示時に更新） |
| 時刻 | 現在の時刻 |
| ページ番号 | 印刷時のページ番号 |
| マージ変数 | 変数の値（`<<$$変数名>>`） |

### マージフィールドとマージ変数

- **マージフィールド**：`<<フィールド名>>` の形式でレイアウトに配置（テキストオブジェクト内）
- **マージ変数**：`<<$変数名>>` や `<<$$変数名>>` でスクリプト変数を表示

---

## 6. 自動サイズ変更（アンカー）（FM24-2.4.7）

### アンカーの仕組み

ウインドウのサイズが変わったときに、オブジェクトをどの位置・サイズに追従させるかを設定。

| アンカー方向 | 効果 |
|------------|------|
| 上/左（デフォルト） | 左上を基準に固定（サイズ変更なし） |
| 右アンカー | 右端に追従（幅が変わる） |
| 下アンカー | 下端に追従（高さが変わる） |

---

## 7. 条件付き書式（FM24-2.4.8）

### 複数の条件付き書式

- 条件は**上から順番に評価**される（Case関数と同じ順序）
- 最初に真になった条件の書式が適用される
- 複数の書式属性（色・太字など）は**それぞれ独立して評価**される場合がある

> **試験頻出：** 「x日前より少ない」オプションは、指定した日数に**現在の日付が含まれる**。

### パフォーマンスへの影響

- 条件付き書式の計算は表示のたびに実行される
- 大量のオブジェクトへの複雑な条件付き書式はパフォーマンスに影響する

---

## 8. オブジェクトの非表示（FM24-2.4.9）

**[次の場合にオブジェクトを隠す]：**
- 計算式が True（1）のとき、そのオブジェクトを非表示にする
- ブラウズモード・検索モード・プレビューモードで動作

---

## 9. レイアウトテーマとスタイル（FM24-2.4.10）

### 書式設定の優先順位（高い順）

1. オブジェクトに直接設定した書式（最高優先）
2. カスタムスタイル
3. テーマのスタイル
4. テーマのデフォルト（最低優先）

### カスタムスタイルとカスタムテーマ

| 項目 | 説明 |
|------|------|
| カスタムスタイル | 特定の状態（通常・ホバー・押下）の書式設定 |
| カスタムテーマ | スタイルの集合。他のファイルにインポートして利用できる |

**利点：**
- 同じ書式を持つオブジェクトを新規配置するたびに書式を再設定する必要がない
- レイアウトのロードが速くなる（パフォーマンス向上）

---

## 10. 動的値一覧（FM24-2.4.11）

### 動的値一覧とは

**リレーションシップに基づいて**、現在のレコードの値に応じて表示内容が変わる値一覧。

**設定方法：**
1. 値一覧の定義で [次のテーブルから関連レコードの値のみ含める] を選択
2. 適切なTOを指定

> **試験頻出：** 「カテゴリに対応する商品のみ表示する動的値一覧」の設定先TOの選択問題が出題される。

## 例題 4-3

レイアウト上の日付フィールドに2つの条件付き書式が設定されています。

- **条件1**：値が空欄 → 塗りつぶし色をピンクに
- **条件2**：値が3日前より少ない（= 3日以内に到来する日付）→ 太字・文字色を赤に

このフィールドに値「2024/12/29」が保存されている場合に、**2025年1月1日**にこのレイアウトを開いたときにフィールドに適用されている書式を選択してください。

なお、このフィールドオブジェクトのデフォルト書式は、スタイルは標準・文字色は黒・塗りつぶし色は白とします。

A. スタイルは標準で文字色は黒、フィールドの塗りつぶし色は白
B. スタイルは太字で文字色は赤、フィールドの塗りつぶし色は白
C. スタイルは太字で文字色は赤、フィールドの塗りつぶし色はピンク

<details>
<summary>解答と解説を見る</summary>

**解答：A**

**解説：**

- 現在の日付：2025/1/1
- フィールドの値：2024/12/29

**条件1（空欄）**：2024/12/29 は空でないので → 適用されない

**条件2（3日前より少ない）**：
- [x日前より少ない] は「現在の日付から x日以内の将来の日付」を意味します
- 指定日数に現在の日付が含まれます
- つまり「3日前より少ない（3日以内）」= 2025/1/1 〜 2025/1/3 の範囲にある日付が対象
- 2024/12/29 は**過去の日付**なので、この条件には一致しない

→ **どちらの条件も適用されないため、デフォルト書式（標準・黒・白）が表示される**

**ポイント：** [x日前より少ない] は「今後x日以内に到来する日付」を意味します。過去の日付には適用されません。

**参考：**
- https://help.claris.com/ja/pro-help/content/conditional-formatting.html

</details>

## 例題 4-5（動的値一覧）

データベースに「注文」「明細」「商品」という3つのテーブルがあります。

- 図1-1：「注文」TO ─ 「注文_明細」TO（照合：注文の主キー）
- 図1-2：「明細」TO ─ 「明細_商品」TO（照合：カテゴリ）

「注文」レイアウト上のポータルに「注文_明細」レコードを表示し、「商品名」フィールドには「明細_商品」レコードの値を使用した値一覧「商品リスト」をポップアップメニューで表示しています。

ポータル上の「商品名」フィールドのポップアップメニューに、「カテゴリ」フィールドに入力された値に対応する商品名だけを表示するための適切な設定を選択してください。

A. 「注文_明細」TOと「明細_商品」TO間に、双方の「カテゴリ」フィールドを照合フィールドとしたリレーションシップを追加し、値一覧「商品リスト」の [次のテーブルから関連レコードの値のみ含める] に「明細_商品」TOを指定する。

B. 値一覧「商品リスト」の [次のテーブルから関連レコードの値のみ含める] に「明細」TOを指定する。

C. 値一覧「商品リスト」の [次のテーブルから関連レコードの値のみ含める] に「明細_商品」TOを指定する。

<details>
<summary>解答と解説を見る</summary>

**解答：B**

**解説：**

動的値一覧の [次のテーブルから関連レコードの値のみ含める] には、**現在のレイアウトのコンテキスト（ポータル内では「注文_明細」TO）から直接リレーションシップが定義されているTO**を指定します。

- ポータルは「注文_明細」TOを表示している
- 「注文_明細」TOと「明細_商品」TOにはカテゴリでリレーションシップが定義されている（図1-2）
- 「明細」TOと「明細_商品」TOのリレーションシップを経由するため、「明細」TOを指定

「明細_商品」TOではなく「明細」TOを指定するのは、ポータルのコンテキストである「注文_明細」TOから見た関連先が「明細」TOであるためです。

**参考：**
- https://help.claris.com/ja/pro-help/content/value-lists.html

</details>

## 重要ポイント一覧

### [レイアウト設定]（FM24-2.4.3）
- [ ] 設定できる：レイアウト名・メニュー表示・デフォルト表示形式・スクリプトトリガ・リスト形式の枠表示
- [ ] 設定できない：**テーマ**（レイアウトメニューから変更）

### レイアウトパート（FM24-2.4.4）
- [ ] 上部/下部ナビゲーション：スクロールしても固定表示
- [ ] 総計パート：全レコードの合計
- [ ] 小計パート（前部/後部）：グループごとの集計

### ポータル（FM24-2.4.5）
- [ ] ソートは [ポータル設定] または [リレーションシップ編集] で設定
- [ ] フィルタは [ポータル設定] の [フィルタ計算式] で設定

### 条件付き書式（FM24-2.4.8）
- [ ] 複数条件は上から評価（最初に真になった条件が適用）
