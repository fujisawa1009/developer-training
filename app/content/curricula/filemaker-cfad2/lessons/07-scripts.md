## 1. 変数の種類（FM24-2.5.1）

### 変数の3種類

| 種類 | 宣言 | スコープ | 寿命 |
|------|------|---------|------|
| **関数変数（Let変数）** | `Let ( 変数名 = 値 ; ... )` | Let式の中のみ | 計算式の評価中 |
| **ローカル変数** | `$変数名` | 実行中のスクリプト内 | スクリプト終了まで |
| **グローバル変数** | `$$変数名` | ファイル内全体（スクリプトをまたぐ） | ファイルを閉じるまで |

### 命名規則

- 変数名は大文字・小文字を区別しない
- スペースは使用不可
- `$` または `$$` で始まる

### 用途の使い分け

| シーン | 使う変数 |
|-------|---------|
| ループカウンタ | ローカル変数 `$i` |
| サブスクリプトへの値の受け渡し（スクリプト引数推奨） | ローカル変数またはスクリプト引数 |
| スクリプトをまたいで共有したい値 | グローバル変数 `$$` |
| 計算式内の一時変数 | Let変数 |

## 2. 主要なアルゴリズム（FM24-2.5.2）

### ループ処理

```
Loop
  [処理]
  Exit Loop If [ 条件 ]  // 条件が True のときループを抜ける
End Loop
```

または

```
Loop
  [処理]
  If [ 条件 ]
    Exit Loop If [ True ]
  End If
End Loop
```

### エラー処理

```
エラー処理 [ オン ]     // エラーが発生してもスクリプトを停止させない
[処理]
If [ Get ( 最終エラー ) ≠ 0 ]
  // エラー時の処理
End If
```

**Get（最終エラー）の主なエラー番号：**

| エラー番号 | 意味 |
|-----------|------|
| 0 | エラーなし |
| 401 | 対象レコードが見つからない |
| 500 | 入力値の制限エラー |
| 508 | 無効な値（フィールドの検証失敗） |

### 条件分岐

```
If [ 条件 ]
  [処理A]
Else If [ 別の条件 ]
  [処理B]
Else
  [処理C]
End If
```

### 検索処理

```
検索モードに移行 [ 一時停止: オフ ]
フィールド設定 [ テーブル::フィールド ; "検索値" ]
検索実行
```

## 3. スクリプトの主要機能（FM24-2.5.3）

### スクリプト引数

スクリプトを呼び出すときに渡す値。

**渡す側：**
- ボタンの設定・スクリプトステップの [スクリプトの実行] のオプション欄で指定

**受け取る側：**
- `Get ( スクリプト引数 )` 関数で受け取る

**形式：**
- 改行区切り：`"値1¶値2¶値3"`
- JSON形式：`JSONSetElement ( "" ; ["key1"; "value1"; JSONString] )`

### 他スクリプトの呼び出し

```
スクリプトの実行 [ "サブスクリプト名" ; 引数: $引数 ]
```

### [完全アクセス権の付与]

- スクリプトに [完全アクセス権の付与] オプションを設定すると、実行ユーザーのアクセス権に関わらず完全アクセス権でスクリプトが実行される
- セキュリティ上の配慮が必要

### [フィールドを名前で設定] スクリプトステップ

- フィールド名を文字列（変数）で動的に指定できる

### 新規ウインドウの作成

| ウインドウスタイル | 特徴 |
|----------------|------|
| ドキュメント | 通常のウインドウ |
| フローティング | 常に前面表示 |
| ダイアログ | モーダルウインドウ（操作が制限される） |
| カード | 親ウインドウの上に表示（背景を暗くする）|

## 4. [関連レコードへ移動]（FM24-2.5.4）

### 主な動作

| オプション | 動作 |
|-----------|------|
| 関連レコードを表示するレイアウト指定 | 別のレイアウトで関連レコードを表示 |
| [現在の対象レコード内のすべてのレコードを照合] | 対象レコード全体の関連レコードを対象にする |
| 新規ウインドウで表示 | 別ウインドウで関連レコードを表示 |

**注意事項：**
- 関連レコードが0件の場合、移動先レイアウトの対象レコードは**0件**になる
- 同じFileMakerファイル内の別レイアウトを指定して新規ウインドウで表示できる

## 5. クライアント対応（FM24-2.5.5）

### FileMaker Go（iOS）での考慮点

- タッチ操作向けのレイアウト設計が必要
- 一部のスクリプトステップはサポートされない
- `Get ( システムプラットフォーム )` で実行環境を判定できる

### FileMaker WebDirect での考慮点

- Webブラウザで動作するため、デスクトップとは動作が異なる場合がある
- 一部のウインドウ操作スクリプトステップが制限される
- パフォーマンスへの配慮が必要

## 6. スクリプトデバッガとデータビューア（FM24-2.5.6）

### スクリプトデバッガ

| 操作 | 動作 |
|------|------|
| **[ステップイン]** | 1ステップずつ実行（サブスクリプトの中にも入る） |
| **[ステップオーバー]** | 1ステップずつ実行（サブスクリプトは中に入らず一括実行） |
| **[ステップアウト]** | **現在のスクリプト内の残りのステップを一括実行**してサブスクリプトを抜ける |
| 実行ボタン（▶） | ブレークポイントがあっても一時停止せず実行し続ける |
| [エラー時に一時停止] | エラー発生時に自動で一時停止 |
| コールスタック | 現在実行中のスクリプトの呼び出し階層を表示 |

> **試験頻出：** [ステップアウト] = 「現在のスクリプト内の残りを実行してから抜ける」（「スキップ」ではない）。

### データビューア

| タブ | 内容 |
|------|------|
| [現在] タブ | 現在のスクリプトのフィールド・変数の値を表示 |
| [監視] タブ | 任意の計算式・フィールド・変数を監視 |

**データビューアでできること：**
- [現在] タブで変数名をダブルクリック → [現在の値] ダイアログが開き、**変数の値を変更できる**
- [現在] タブでフィールド名をダブルクリック → [現在の値] ダイアログが開くが、**フィールド値は変更できない**

## 例題 5-1

次のスクリプトにスクリプト引数「3」を渡して実行した後の「テーブル::数字」フィールドの値を選択してください。なお、スクリプト実行前の「テーブル::数字」フィールドの値は「100」とします。

```
計算  （スクリプト名）

1: 変数を設定 [ $arg ; 値: Get ( スクリプト引数 ) ]
2: 変数を設定 [ $amount ; 値: 0 ]
3:
4: If [ $arg > 0 ]
5:   変数を設定 [ $sum ; 値: While ( [ amount = 0 ] ; $arg > 1 ; [ amount = amount + $arg ; $arg = $arg -1 ] ; amount ) ]
6: Else If [ $arg > 2 ]
7:   変数を設定 [ $sum ; 値: $arg ]
8: End If
9:
10: フィールド設定 [ テーブル::数字 ; $amount + $arg ]
```

A. 1
B. 3
C. 8
D. 9
E. 100

<details>
<summary>解答と解説を見る</summary>

**解答：A**

**解説：**

スクリプト引数 `$arg = 3` で実行。

**Step 1:** `$arg = 3`
**Step 2:** `$amount = 0`

**Step 4:** `$arg > 0` → `3 > 0` → True → Step 5へ

**Step 5:** While 関数の評価
```
While (
  [amount = 0],           // 初期化：amount = 0
  $arg > 1,              // 継続条件：$arg > 1 の間ループ
  [amount = amount + $arg ; $arg = $arg - 1],  // 処理
  amount                 // 結果
)
```

ループの流れ：
- 初期：amount = 0, $arg = 3
- 繰り返し1：3 > 1 → True → amount = 0 + 3 = 3, $arg = 3 - 1 = 2
- 繰り返し2：2 > 1 → True → amount = 3 + 2 = 5, $arg = 2 - 1 = 1
- 繰り返し3：1 > 1 → False → ループ終了

While の結果（amount）= 5

しかし **While 関数はローカルスコープ** なので、スクリプト変数 `$amount` と `$arg` は変わりません。
`$sum = 5`（While内のローカル変数の結果）

**Step 10:** `テーブル::数字 = $amount + $arg = 0 + 1 = 1`

（$amount は Step 2で設定した0のまま、$arg は Step 1で設定した3のまま。While の中の変数変更はWhile内のスコープのみ）

**→ 結果：1**

**参考：**
- https://help.claris.com/ja/pro-help/content/while.html
- https://help.claris.com/ja/pro-help/content/using-variables.html

</details>

[関連レコードへ移動] スクリプトステップについての適切な記述を**すべて**選択してください。

A. 同じ FileMaker Pro ファイル内の別のレイアウトを指定し、新規ウインドウで表示できる。

B. 関連レコードが1件もない場合、移動先のレイアウトでの対象レコードは0件になる。

C. 現在の対象レコードのいずれかに関連する関連レコードを対象レコードにするには、[現在の対象レコード内のすべてのレコードを照合] オプションを選択する。

## 例題 5-3

FileMaker Pro のスクリプトデバッガとデータビューアについて、適切な記述を**すべて**選択してください。

A. スクリプトデバッガで [ステップイン] を選択すると、サブスクリプトを表示せずに、スクリプトを一度に1ステップずつ実行する。

B. スクリプトデバッガで [ステップアウト] を選択すると、現在のスクリプト内のすべてのスクリプトステップを実行する。

C. スクリプトデバッガで実行ボタン（▶）をクリックすると、ブレークポイントを設定していても一時停止せず、スクリプトが終了するまで実行される。

D. データビューアの [現在] タブにおいて、変数名が表示されている行をダブルクリックすると [現在の値] ダイアログボックスが開き、変数の値を変更することができる。

E. データビューアの [現在] タブにおいて、フィールド名が表示されている行をダブルクリックすると [現在の値] ダイアログボックスが開き、フィールド値を変更することができる。

<details>
<summary>解答と解説を見る</summary>

**解答：B, D**

**解説：**
- **A（×）**：[ステップイン] はサブスクリプトの**中にも入って**1ステップずつ実行します。「サブスクリプトを表示せず」は [ステップオーバー] の説明です。
- **B（○）**：[ステップアウト] は現在のスクリプト内の**残りのすべてのステップを実行して**から抜けます。
- **C（×）**：実行ボタン（▶）はブレークポイントがある場合は**ブレークポイントで一時停止します**。ブレークポイントを無視して最後まで実行するわけではありません。
- **D（○）**：変数の行をダブルクリックすると [現在の値] ダイアログが開き、変数の値を変更できます。
- **E（×）**：フィールドの行をダブルクリックすると [現在の値] ダイアログが開きますが、**フィールド値は変更できません**（読み取りのみ）。

**参考：**
- https://help.claris.com/ja/pro-help/content/debugging-scripts.html
- https://help.claris.com/ja/pro-help/content/data-viewer.html

## ポイントまとめ

| 項目 | 重要ポイント |
|------|------------|
| While 関数 | 内部の変数変更はWhileスコープのみ（スクリプト変数には影響しない） |
| [ステップイン] | サブスクリプトの中にも入る |
| [ステップアウト] | 現在スクリプトの残りを実行（スキップではない） |
| データビューア | 変数は値変更可、フィールドは変更不可（読み取りのみ） |
| 実行ボタン | ブレークポイントで一時停止する |

---

## 重要ポイント一覧

### 変数（FM24-2.5.1）
- [ ] 関数変数（Let）：計算式内のみ
- [ ] ローカル変数（$）：スクリプト内のみ
- [ ] グローバル変数（$$）：ファイル内全体・スクリプト間をまたぐ

### While 関数の特性（FM24-2.5.2）
- [ ] While内の変数変更はWhile内のスコープのみ
- [ ] スクリプト変数（$arg など）はWhileの外から見ると変化しない

### デバッガ操作（FM24-2.5.6）
- [ ] [ステップイン]：サブスクリプトの中にも入る
- [ ] [ステップオーバー]：1ステップずつ（サブスクリプトは一括）
- [ ] [ステップアウト]：現在スクリプトの残りを実行して抜ける
- [ ] 実行ボタン（▶）：ブレークポイントで一時停止する
- [ ] データビューアで変数の値は変更可能、フィールド値は変更不可

### [関連レコードへ移動]（FM24-2.5.4）
- [ ] 同じファイル内の別レイアウトを新規ウインドウで表示できる
- [ ] [すべてのレコードを照合] で対象レコード全体の関連レコードを対象にできる
- [ ] 関連レコードが0件なら移動先は0件になる

## 試験対策メモ

```
デバッガの操作（頻出）
  ステップイン    → サブスクリプトにも入る
  ステップオーバー → サブスクリプトは中に入らない
  ステップアウト  → 残りを実行して（スキップじゃない）抜ける
  実行ボタン     → ブレークポイントで止まる

データビューア
  変数のダブルクリック → 値変更できる
  フィールドのダブルクリック → 読み取りのみ（変更不可）
```
