## 1. Web ビューア（FM24-2.4.12）

### Web ビューアで表示できるもの

| 種類 | 設定 |
|------|------|
| Web ページ | URLを指定 |
| FileMaker のデータ | データURLを使用してHTMLを生成 |
| カスタムWebアドレス | 計算式でURLを動的に生成 |

### [Web ビューアの設定] ダイアログ

- Web アドレス：計算式で動的なURLを指定可能
- **カスタム Web アドレス**：`"data:text/html," & HTMLコンテンツ` のようにデータURLでHTMLを直接表示
- [FileMaker スクリプトの実行を許可（JavaScript）]：WebビューアからFileMakerスクリプトを呼び出す際に必要

## 2. グラフツール（FM24-2.4.13）

### グラフのデータソース

| データソース | 説明 |
|------------|------|
| 現在の対象レコード（個々のレコードデータ） | 対象レコードの各フィールド値をデータとして使用 |
| 現在の対象レコード（集計レコードグループ） | 集計パートのグループごとの集計値を使用 |
| 現在のレコード（区切りデータ） | 現在のレコードの繰り返しフィールド値を使用 |
| 関連レコード | 関連テーブルのレコードを使用 |

### グラフタイプ

棒グラフ・横棒グラフ・折れ線グラフ・円グラフ・面グラフ・散布図・バブルチャートなど。

## 3. スクリプトトリガ（FM24-2.4.14・FM24-2.4.15）

### スクリプトトリガの設定対象

| 対象 | 設定可能なトリガ例 |
|------|----------------|
| ファイル | OnFirstWindowOpen、OnLastWindowClose |
| レイアウト | OnLayoutEnter、OnLayoutExit |
| レイアウトオブジェクト | OnObjectEnter、OnObjectKeystroke、OnObjectModify、OnObjectSave、OnObjectValidate |

### スクリプトトリガの実行順序（頻出）

ユーザーがテキストフィールドに値を入力してレコードを確定したときの順序：

```
① OnObjectEnter      → フィールドに入る
② OnObjectKeystroke  → キー入力のたびに
① OnLayoutKeystroke  → レイアウトのキーストロークより後
④ OnObjectValidate   → 入力値の検証
⑤ OnObjectSave       → フィールドを確定（レコード確定前）
⑥ OnRecordCommit     → レコードを確定
```

**注意：** OnObjectKeystroke と OnLayoutKeystroke の順序は：
`OnObjectEnter → OnObjectKeystroke → OnLayoutKeystroke`

（OnObjectKeystroke の方が OnLayoutKeystroke より先に実行される）

> **試験頻出：** スクリプトトリガの実行順序が問われる問題が出題される（例題 4-6参照）。

### よく使われるスクリプトトリガ

| トリガ | 発動タイミング | 用途例 |
|-------|-------------|-------|
| OnObjectSave | フィールド確定時 | 入力値の後処理 |
| OnFirstWindowOpen | ファイルを開いたとき | 初期化処理 |
| OnLastWindowClose | ファイルを閉じるとき | 終了処理 |
| OnLayoutEnter | レイアウトに入るとき | レイアウト切り替え時の初期化 |
| OnObjectModify | フィールド値が変更されたとき | リアルタイム検証・連動処理 |

## 5. カスタムメニュー（FM24-2.4.17）

### カスタムメニューの作成

**[高度なツールを利用する] が必要。**

1. [ファイル] → [管理] → [カスタムメニュー] で [カスタムメニューの管理] ダイアログを開く
2. カスタムメニューを作成し、カスタムメニューセットに追加

### カスタムメニューセットの適用方法

| 方法 | 説明 |
|------|------|
| [カスタムメニューの管理] ダイアログ | ファイルのデフォルトとして指定 |
| [レイアウト設定] | レイアウトごとにメニューセットを指定 |
| [カスタムメニューのインストール] スクリプトステップ | スクリプトで動的に切り替える |
| [ツール] メニュー → [カスタムメニュー] | **ブラウズモードからの操作（適用方法ではなく確認用）** |

> **試験頻出：** 「カスタムメニューセットを使用する方法として**適切でないもの**」として、[環境設定] ダイアログでの指定が選択肢に出ることがある（[環境設定] での指定は**できない**）。

## 例題 4-6

ユーザーがレイアウト上のテキストフィールドに値を入力してレコードを確定したとき、次の5つのスクリプトトリガが、実行される優先順に左から並んでいるものを選択してください。なお、スクリプトトリガはすべて設定されており、実行されるものとします。

- (1) OnLayoutKeystroke
- (2) OnObjectKeystroke
- (3) OnObjectEnter
- (4) OnObjectValidate
- (5) OnRecordCommit

A. (3) → (1) → (2) → (5) → (4)
B. (3) → (1) → (2) → (4) → (5)
C. (3) → (2) → (1) → (4) → (5)
D. (4) → (3) → (1) → (2) → (5)

<details>
<summary>解答と解説を見る</summary>

**解答：C**

**解説：**

正しい実行順序：
```
(3) OnObjectEnter → フィールドに入ったとき（最初に1回）
(2) OnObjectKeystroke → キーを押すたびに（オブジェクト優先）
(1) OnLayoutKeystroke → OnObjectKeystroke の後
(4) OnObjectValidate → フィールド確定前に入力値を検証
(5) OnRecordCommit → レコードが確定するとき
```

**重要ポイント：**
- OnObjectKeystroke は OnLayoutKeystroke より**先に**実行される（オブジェクト優先）
- OnObjectValidate は OnObjectSave より前、OnRecordCommit より前
- OnObjectEnter は最初の1回のみ

**参考：**
- https://help.claris.com/ja/pro-help/content/script-triggers.html

</details>

## 例題 4-7

作成したカスタムメニューセットを使用する方法として、**適切でない記述**を選択してください。

A. [環境設定] ダイアログボックスの [一般] タブで、FileMaker Pro アプリケーションのデフォルトのメニューセットとして指定する。

B. [カスタムメニューの管理] ダイアログボックスで、カスタム App ファイルのデフォルトのメニューセットとして指定する。

C. [レイアウト設定] ダイアログボックスで、レイアウトごとに使用するメニューセットを指定する。

D. ブラウズモードで [ツール] メニューの [カスタムメニュー] から使用するメニューセットを選択する。

E. [メニューセットのインストール] スクリプトステップを使ったスクリプトで切り替える。

<details>
<summary>解答と解説を見る</summary>

**解答：A**

**解説：**
- **A（×・不適切）**：[環境設定] ダイアログでカスタムメニューセットをデフォルトとして指定する機能は**ありません**。これが「適切でない記述」です。
- **B（○）**：[カスタムメニューの管理] でファイルのデフォルトを設定できます。
- **C（○）**：[レイアウト設定] でレイアウトごとにメニューセットを指定できます。
- **D（○）**：ブラウズモードの [ツール] メニューから切り替えられます（確認・操作用）。
- **E（○）**：[カスタムメニューのインストール] スクリプトステップで動的に切り替えられます。

**参考：**
- https://help.claris.com/ja/pro-help/content/custom-menus.html

</details>
