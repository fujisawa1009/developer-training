## 1. アクセス権セット（FM24-2.6.1）

### アクセス権セットの構成

| 項目 | 設定内容 |
|------|---------|
| レコードアクセス権 | テーブルごとに閲覧・作成・編集・削除の権限を設定 |
| レイアウトアクセス権 | レイアウトへのアクセスと変更権限 |
| 値一覧アクセス権 | 値一覧の使用と変更権限 |
| スクリプトアクセス権 | スクリプトの実行・変更権限 |
| その他のアクセス権 | 印刷・エクスポートなど |

### 拡張アクセス権

特定の機能を許可するかどうかを制御。

| 拡張アクセス権 | 意味 |
|------------|------|
| FileMaker WebDirect によるアクセス（fmwebdirect） | WebDirectでのアクセスを許可 |
| ODBC/JDBC によるアクセス（fmxdbc） | ODBC/JDBCでのアクセスを許可 |
| FileMaker ネットワークによるアクセス（fmapp） | FileMaker Pro/GoでのFileMaker Server接続を許可 |

> **試験頻出：** 「FileMaker WebDirect でアクセスできるが、FileMaker Pro からは開けない」という状態は、fmwebdirect のみ許可して fmapp を許可していない場合。

### アクセス権セットの設定例の読み方

```
レコード：カスタムアクセス権...
レイアウト：すべて表示のみ
値一覧：すべて表示のみ
スクリプト：すべて実行のみ可能

拡張アクセス権：
  ✓ FileMaker WebDirect によるアクセス（fmwebdirect）
  □ ODBC/JDBC
  □ FileMaker ネットワーク（fmapp）

その他：
  □ 印刷を許可
  □ エクスポートを許可
```

この設定では：
- Web Direct でアクセス可能だが FileMaker Pro では**開けない**（fmapp なし）
- 印刷・PDFへの保存はできない（[印刷を許可] がオフ）
- スクリプトは実行できる

## 2. ファイルの暗号化（FM24-2.6.2）

### 暗号化の手順

**[高度なツールを利用する] が選択されている必要があります。**

1. [ツール] メニュー → [Developer ユーティリティ]
2. [データベースの暗号化] を選択
3. 暗号化パスワードと共有IDを設定

### 暗号化の設定

| 項目 | 内容 |
|------|------|
| 暗号化パスワード | ファイルを暗号化/復号化するためのパスワード |
| 共有ID | 複数ファイルで同じIDを設定すると一度の認証でアクセス可能 |

### 暗号化に関する注意点

- **共有ID**：大文字と小文字は**区別されない**（試験頻出）
- **オープン格納のオブジェクトフィールド**：暗号化しても強制的にセキュア格納に変更される**わけではない**
- **マルチファイルカスタム App**：全ファイルを同じパスワードと共有IDで暗号化すると、起動時に何度もパスワード入力が求められなくなる

## 3. フィールド内容のエクスポート（FM24-2.7.1）

### [フィールド内容のエクスポート] コマンド

**[編集] メニュー → [フィールド内容のエクスポート]**

| 特性 | 内容 |
|------|------|
| 対象 | 現在選択されているフィールドの内容 |
| テキストフィールド | UTF-16形式のテキストファイルとして書き出す |
| 出力ファイルの暗号化 | **できない**（暗号化オプションはない） |
| エクスポート先 | フォルダを新規作成してエクスポートできる |
| FileMaker WebDirect | Webブラウザのデフォルトのダウンロード先にエクスポート |

## 4. データのインポート（FM24-2.7.2）

### インポートの種類

| 種類 | 動作 |
|------|------|
| 追加 | すべてのレコードを新規追加 |
| 更新（既存レコードの更新） | 照合フィールドで一致したレコードを更新 |
| 置換（対象レコードを更新） | 対象レコードを順番に置換 |

### インポート時のフィールドオプション処理

| 設定 | インポート時の動作 |
|------|----------------|
| 入力値の自動化 | インポート時にも実行される（[インポート中にフィールドに対して入力値の自動化オプションを実行] チェックがある）|
| ハウスキーピングフィールド | インポート設定でインポートしない設定にしている場合、**入力値の自動化が実行されない** |
| 索引 | インポート後に索引が生成・更新される |
| スクリプトトリガ | **インポート時には発動しない**（OnRecordCommitなど）|

### [置換] インポートの注意点

- 現在の対象レコードの先頭からソースファイルのデータで**順番に**置き換える
- ハウスキーピングフィールドをインポートしない設定でも、入力値の自動化は実行される場合がある（設定依存）
- 更新されたレコードの主キー・作成情報タイムスタンプ・作成者フィールドは**更新されない**（作成情報は作成時の情報で変わらない）

## 5. データのエクスポート（FM24-2.7.3）

### エクスポートに必要なアクセス権

- [エクスポートを許可] アクセス権が必要
- デフォルトのアクセス権セットの [データ入力のみ] はエクスポート**不可**、[閲覧のみアクセス] はエクスポート**不可**

### エクスポート方法

| 方法 | 説明 |
|------|------|
| [ファイル] → [レコードのエクスポート] | 対象レコードを一括エクスポート |
| [編集] → [フィールド内容のエクスポート] | 選択フィールドの内容のみ |
| ショートカットメニュー | フィールド上で右クリック → [フィールド内容のエクスポート] |

## 6. FileMaker WebDirect（FM24-2.8.1）

### FileMaker WebDirect の特徴

- FileMaker Server または FileMaker Cloud でホストされているカスタム App を Web ブラウザで使用
- ゲストアカウントを使うことで、パスワードなしでアクセスできる

### FileMaker WebDirect の制限

| 機能 | WebDirect |
|------|----------|
| 表形式 | サポートしていない（試験頻出） |
| 一部のスクリプトステップ | 動作しないものがある（例：電子メールクライアント経由のメール送信） |
| ウインドウ操作 | 制限がある |

> **試験頻出：** FileMaker WebDirect は表形式をサポート**していない**。

### WebDirect へのアクセス

- **拡張アクセス権 [fmwebdirect]** が必要
- ゲストアカウントに fmwebdirect を許可すると、パスワードなしでアクセスできる

## 例題 6-1

FileMaker Pro のアクセス権セットについて、適切な記述を**すべて**選択してください。

A. 拡張アクセス権 [fmwebdirect] を許可すると、FileMaker WebDirect でアクセスできるが、[fmapp] を許可しなければ FileMaker Pro からは開けない。

B. [データ入力のみ] アクセス権セットでは、データのエクスポートが許可されている。

C. スクリプトに [完全アクセス権の付与] オプションを設定すると、実行ユーザーのアクセス権に関わらず完全アクセス権でスクリプトが実行される。

D. 拡張アクセス権 [fmxdbc] は、ODBC/JDBC によるアクセスを許可する。

<details>
<summary>解答と解説を見る</summary>

**解答：A, C, D**

**解説：**
- **A（○）**：`fmwebdirect` のみ許可して `fmapp` を許可していない場合、WebDirect からはアクセスできますが、FileMaker Pro（ネットワーク経由）からは開けません。

B. 索引が設定されているフィールドへのインポートが完了すると、索引が生成・更新される。
