## 自社を客観的に見るために

外部環境の分析（PEST・5Forces・3C）が終わったら、次は**自社と事業の方向性**を整理します。SWOT分析で現状を把握し、STP分析で「誰に・何を・どう届けるか」を明確にします。

---

## SWOT分析

**SWOT分析**は、自社の状況を「内部環境」と「外部環境」の2軸、「プラス要因」と「マイナス要因」の2軸の計4象限で整理するフレームワークです。

```
              │ プラス要因       │ マイナス要因
──────────────┼─────────────────┼─────────────────
内部環境       │ S: Strengths    │ W: Weaknesses
（自社）       │    強み         │    弱み
──────────────┼─────────────────┼─────────────────
外部環境       │ O: Opportunities│ T: Threats
（市場・競合） │    機会         │    脅威
──────────────┴─────────────────┴─────────────────
```

### 各象限の分析例

**S（強み）**
- ブランド認知度・特許・技術力
- 優秀な人材・独自のノウハウ
- 財務基盤の安定

**W（弱み）**
- リソース（人・金・時間）の不足
- 技術・プロセスの遅れ
- ブランド力の低さ

**O（機会）**
- 市場の成長・新技術の台頭
- 規制の緩和・社会ニーズの変化
- 競合の撤退

**T（脅威）**
- 強力な競合の参入
- 市場の縮小・規制強化
- 代替技術の台頭

### クロスSWOT：戦略を導き出す

SWOT分析の真価は、4象限を**クロス（組み合わせ）させて戦略を導くこと**にあります。

| 組み合わせ | 戦略の方向性 | 考え方 |
|---|---|---|
| S × O（積極戦略） | 強みを活かして機会を掴む | 最も攻めやすい |
| S × T（差別化戦略） | 強みで脅威を回避する | 競合との差別化 |
| W × O（改善戦略） | 弱みを補強して機会を活かす | 弱みの克服 |
| W × T（撤退・縮小戦略） | 最悪の事態を回避する | リスク最小化 |

## STP分析

**STP分析**は、マーケティング戦略の基本です。市場をどう分けて（Segmentation）、どこを狙って（Targeting）、どう位置づけるか（Positioning）を整理します。

```
S → T → P
分ける → 狙う → 差別化する
```

### S：セグメンテーション（市場を分割する）

市場を意味のある単位（セグメント）に分けます。

| 分類軸 | 具体例 |
|---|---|
| デモグラフィック | 年齢・性別・年収・職業・家族構成 |
| ジオグラフィック | 地域・都市規模・気候 |
| サイコグラフィック | ライフスタイル・価値観・趣味 |
| ビヘイビアル | 購買頻度・ブランドへの態度・利用シーン |

**良いセグメントの条件（4R）**

- **Rank**（優先順位がつけられる）
- **Realistic**（十分な市場規模がある）
- **Reachable**（アプローチ可能）
- **Response**（マーケティングへの反応が見込める）

### T：ターゲティング（セグメントを選択する）

分割したセグメントの中から、自社が集中して狙うべきターゲットを選びます。

| 戦略 | 内容 | 例 |
|---|---|---|
| 無差別型 | 全セグメントに同じ施策 | 大量販売の日用品 |
| 差別型 | セグメントごとに施策を変える | 自動車メーカーの複数ライン |
| 集中型 | 一つのセグメントに絞る | 高級ブランド・ニッチ製品 |

### P：ポジショニング（差別化ポイントを明確にする）

選んだターゲットの頭の中で、自社製品・サービスをどう位置付けるかを決めます。

**ポジショニングマップ**を使うと視覚的に整理できます。

```
         高品質
           ▲
           │      ●自社
           │
低価格 ────┼──── 高価格
           │  ●競合A
           │
           ▼
         低品質
```

ポジショニングは**2軸で表現**します。軸の選び方がポジショニング戦略の核心です。

---

## SWOT × STP の使い方

1. **PEST・5Forces・3C** で外部環境を分析する
2. **SWOT** で自社の強み・弱みと機会・脅威を整理する
3. **STP** で「どの顧客に・どう差別化して届けるか」を決める

> SWOT分析はよく「埋めて終わり」になりがちです。必ずクロスSWOTまで進め、「だから自社はこの戦略を取る」という結論を導きましょう。
