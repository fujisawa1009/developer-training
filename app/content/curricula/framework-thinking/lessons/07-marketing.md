## マーケティングフレームワークとは

マーケティングの目的は**「正しい顧客に、正しい価値を、正しい方法で届けること」**です。フレームワークを使うことで、その戦略を体系的に設計・評価できます。

---

## 4P / 4C

### 4P（企業視点）

**4P**は、マーケティングミックスの基本フレームワークです。企業が「どう売るか」を設計するための4要素です。

| P | 内容 | 問い |
|---|---|---|
| **Product（製品）** | 何を売るか | どんな価値・機能・品質を提供するか |
| **Price（価格）** | いくらで売るか | どんな価格戦略を取るか |
| **Place（流通）** | どこで売るか | どのチャネルで届けるか |
| **Promotion（販促）** | どう知ってもらうか | 広告・PR・販促をどう展開するか |

### 4C（顧客視点）

**4C**は4Pを顧客視点で再解釈したフレームワークです。

| C | 対応するP | 顧客視点の問い |
|---|---|---|
| **Customer Value（顧客価値）** | Product | 顧客にとっての価値・便益は何か |
| **Cost（顧客コスト）** | Price | 顧客が払うコスト（金銭・手間・時間） |
| **Convenience（利便性）** | Place | 顧客が購入・利用しやすいか |
| **Communication（コミュニケーション）** | Promotion | 顧客との双方向のコミュニケーションができているか |

### 4P × 4Cの活用

> 4Pは「自社が提供したいもの」、4Cは「顧客が求めるもの」。両者を照合することで、ズレを発見できる。

## AIDMA / AISAS（購買行動モデル）

購買行動モデルは、顧客が「認知」から「購買」に至るまでのプロセスを整理します。

### AIDMA（マスメディア時代）

```
A → I → D → M → A
認知  関心  欲求  記憶  行動
```

| ステップ | 内容 | 施策例 |
|---|---|---|
| **Attention（注意）** | 存在を知る | TV・新聞広告・OOH |
| **Interest（関心）** | 興味を持つ | 詳細な商品説明・比較記事 |
| **Desire（欲求）** | 欲しいと思う | レビュー・体験談・デモ |
| **Memory（記憶）** | 覚えている | リマインド広告・メルマガ |
| **Action（行動）** | 購入する | クーポン・期間限定オファー |

### AISAS（デジタル時代）

インターネット・SNS時代の購買行動モデルです。

```
A → I → S → A → S
認知  関心  検索  行動  共有
```

| ステップ | 内容 | 施策例 |
|---|---|---|
| **Attention** | 存在を知る | SNS広告・インフルエンサー |
| **Interest** | 興味を持つ | コンテンツマーケ・SEO |
| **Search（検索）** | 自分で調べる | SEO・口コミ・レビュー対策 |
| **Action** | 購入する | ECサイト・LP最適化 |
| **Share（共有）** | SNSでシェア | UGC施策・ハッシュタグ |

> AISASのポイントは「Share」。顧客が自発的に拡散することが新たな「Attention」を生む。

## カスタマージャーニー

**カスタマージャーニー**は、顧客が製品・サービスを知り、使い続けるまでの全体的な体験の流れを「旅（Journey）」として可視化するフレームワークです。

### カスタマージャーニーマップの構成

```
フェーズ  │認知    │検討    │購入    │利用    │継続・推奨
─────────┼───────┼───────┼───────┼───────┼────────
行動      │SNSで見る│サイト比較│購入する │使い始める│友人に薦める
─────────┼───────┼───────┼───────┼───────┼────────
思考・感情 │「面白そう」│「これでいいか」│「早く試したい」│「使いやすい」│「おすすめしたい」
─────────┼───────┼───────┼───────┼───────┼────────
タッチ    │Instagram│比較サイト│公式EC  │アプリ  │レビュー投稿
ポイント  │広告    │口コミ  │決済画面 │サポート │メルマガ
─────────┼───────┼───────┼───────┼───────┼────────
課題・     │認知が低い│競合比較 │離脱率高 │操作が難 │継続率低
ペインポイント│       │        │        │        │
```

### 活用のポイント

- **顧客視点**で書く（自社の施策を起点にしない）
- ペインポイント（不満・摩擦）を特定して改善に活かす
- 定量データ（CVR・解約率）と定性データ（インタビュー）を組み合わせる

## LTV（顧客生涯価値）

**LTV（Life Time Value：顧客生涯価値）**は、1人の顧客が取引を続ける期間にわたって自社にもたらす総収益です。

### LTVの計算式

```
LTV = 平均購買単価 × 購買頻度 × 継続期間
```

または

```
LTV = 顧客1人あたりの月次収益 ÷ チャーン率（解約率）
```

### LTVを使った意思決定

| 指標 | 内容 |
|---|---|
| **LTV > CAC** | 事業として健全（CAC：顧客獲得コスト） |
| **LTV/CAC ≥ 3** | SaaSの健全指標の目安 |
| **LTV向上施策** | アップセル・クロスセル・解約率改善・利用頻度向上 |

### LTVとファネル分析

```
認知（100人）
   ↓ 50%
関心（50人）
   ↓ 40%
検討（20人）
   ↓ 50%
購入（10人）     ← ここまでがCAC（獲得コスト）の範囲
   ↓ 80%継続
継続（8人/月）   ← ここからがLTVの範囲
```

## まとめ：マーケティングフレームワークの連携

```
① 4P/4C       → 「何を・いくらで・どこで・どう届けるか」を設計する
② AIDMA/AISAS → 「顧客がどう動くか」のプロセスを理解する
③ カスタマー  → 「顧客の体験全体」を可視化する
   ジャーニー
④ LTV         → 「1人の顧客の価値」を定量的に評価する
```

> マーケティングは「売る」のではなく「顧客に価値を届け続けること」。フレームワークを使って、顧客の立場で考える習慣を身につけましょう。
