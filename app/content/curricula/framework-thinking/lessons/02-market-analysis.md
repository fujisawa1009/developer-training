## なぜ市場・競合を分析するのか

ビジネスの意思決定は「外部環境」の理解なしには成り立ちません。市場の動向、競合の戦略、マクロな環境変化を把握することで、**自社が取るべき戦略の方向性**が見えてきます。

---

## 3C分析

**3C分析**は、Customer（顧客）・Competitor（競合）・Company（自社）の3つの視点から事業環境を整理するフレームワークです。

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│ Customer │     │Competitor│     │ Company  │
│  顧客    │     │  競合    │     │  自社    │
│・ニーズ  │     │・戦略    │     │・強み    │
│・規模    │     │・シェア  │     │・弱み    │
│・購買行動│     │・差別化  │     │・リソース│
└──────────┘     └──────────┘     └──────────┘
```

### 分析の順番

1. **Customer（顧客）から始める**
   市場規模・顧客のニーズ・購買動機・未充足ニーズを把握する

2. **Competitor（競合）を把握する**
   主要競合の戦略・強み・弱み・シェアを整理する

3. **Company（自社）を評価する**
   顧客・競合との比較で自社の強みと弱みを客観視する

### KSF（Key Success Factor）を見つける

3Cの交点に**成功の鍵（KSF）**があります。

- 顧客が求めているが、競合がまだ提供していないこと
- 自社が提供でき、顧客が価値を感じること

---

## PEST分析

**PEST分析**は、事業に影響を与えるマクロな外部環境を4つの視点で整理するフレームワークです。

| 要素 | 英語 | 分析する内容 | 例 |
|------|------|------------|---|
| P | Political（政治） | 法規制・政策・税制・貿易 | 個人情報保護法の強化 |
| E | Economic（経済） | 景気・物価・為替・雇用 | 円安による原材料費高騰 |
| S | Social（社会） | 人口動態・文化・価値観 | 少子高齢化・副業解禁 |
| T | Technological（技術） | 技術革新・DX・自動化 | 生成AIの普及 |

### 使い方のポイント

- **機会（Opportunity）と脅威（Threat）**に分類して整理する
- 現在だけでなく**将来のトレンド**も予測して分析する
- SWOT分析の「外部環境」インプットとして活用する

---

## 5Forces分析（ファイブフォース）

**5Forces分析**は、マイケル・ポーターが提唱した業界の競争構造を分析するフレームワークです。業界の「儲けやすさ（収益性）」を左右する5つの力を分析します。

```
                    ┌──────────────┐
                    │  新規参入者  │
                    │（参入障壁）  │
                    └──────┬───────┘
                           │
   ┌──────────┐    ┌───────▼───────┐    ┌──────────┐
   │ 売り手の │    │               │    │ 買い手の │
   │  交渉力  │◄───│  業界内競合   │───►│  交渉力  │
   │（仕入先）│    │   （競争）    │    │ （顧客） │
   └──────────┘    └───────┬───────┘    └──────────┘
                           │
                    ┌──────┴───────┐
                    │  代替品の脅威 │
                    └──────────────┘
```

### 5つの力

| 力 | 内容 | 強いと収益性が低くなる理由 |
|----|------|--------------------------|
| ① 業界内の競合 | 既存競合との価格・品質競争 | 価格競争が激化する |
| ② 新規参入の脅威 | 新しいプレイヤーが入ってくる容易さ | シェアが奪われる |
| ③ 代替品の脅威 | 別の手段で同じニーズが満たされる可能性 | 顧客が流れる |
| ④ 売り手の交渉力 | 仕入先・サプライヤーの力 | コストが上がる |
| ⑤ 買い手の交渉力 | 顧客・バイヤーの価格交渉力 | 売価が下がる |

### 活用シーン

- 新規事業の市場参入判断
- 業界の競争環境の把握
- 競争優位を築くための戦略立案

---

## 3C・PEST・5Forcesの使い分け

| フレームワーク | 最適な用途 | 粒度 |
|---|---|---|
| 3C分析 | 事業・サービスの競争環境を整理する | ミクロ |
| PEST分析 | マクロな外部環境変化を把握する | マクロ |
| 5Forces | 業界の収益構造・参入判断をする | 中間 |

> 実践では、PEST → 5Forces → 3C の順で「大から小へ」分析を進めると、環境の全体像を捉えやすくなります。
