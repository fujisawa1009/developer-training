## レッスン07 模範解答：マーケティングで考える（4P/4C / AIDMA/AISAS / カスタマージャーニー / LTV）

---

### 問題1：4P / 4C分析（スマートウォッチ）

**4P（企業視点）**

| P | 内容 |
|---|---|
| **Product（製品）** | 心拍数・睡眠・歩数の計測機能付きスマートウォッチ。専用アプリと連携してデータを可視化 |
| **Price（価格）** | 3万円台（プレミアム価格帯） |
| **Place（流通）** | 家電量販店（店頭） + ブランド公式オンラインストア |
| **Promotion（販促）** | テレビCM + 著名スポーツ選手によるインフルエンサー施策 |

**4C（顧客視点）**

| C | 対応するP | 顧客視点 |
|---|---|---|
| **Customer Value（顧客価値）** | Product | 「健康管理を手軽に、毎日続けられる」という価値。ただし機能が多すぎて何が嬉しいかわかりにくい可能性がある |
| **Cost（顧客コスト）** | Price | 3万円台は健康意識が高い層には許容できるが、初回購入のハードルが高い。アプリの継続利用料がかかるかも不明 |
| **Convenience（利便性）** | Place | 家電量販店で実機を確認できる点は良いが、購入後のアプリ設定・連携の手間が顧客の負担になる可能性 |
| **Communication（コミュニケーション）** | Promotion | テレビCMは認知に有効だが、一方向の発信。健康管理ツールとして購入した後のユーザーコミュニティやフィードバックの仕組みが不足している可能性 |

**4Pと4Cのズレ：**

1. **Place（流通）× Convenience（利便性）のズレ**：実機は量販店で確認できるが、購入後のアプリ設定や使い始めのオンボーディングが複雑で顧客コストが高い可能性がある。購入後のセットアップ動画やサポート強化が必要。

2. **Promotion（販促）× Communication（コミュニケーション）のズレ**：テレビCM・スポーツ選手起用は認知拡大には有効だが、健康管理ツールのユーザーは「使い続けることで効果が出る」ため、購入後の継続使用を促す双方向コミュニケーション（アプリ内通知・ユーザーコミュニティ）が不足している。

> **採点ポイント**：4Pの各要素が正しく整理されているか。4Cへの変換が「顧客視点」で書かれているか。ズレの指摘が「自社が提供したいことと顧客が求めることのギャップ」として具体的に述べられているかがポイント。

### 問題2：LTVの計算と活用

**① LTVの計算**

```
LTV = 月次収益 ÷ チャーン率
    = 3,000円 ÷ 0.04
    = 75,000円
```

**② LTV/CAC比率と健全性の判断**

```
LTV/CAC = 75,000円 ÷ 18,000円 = 4.17
```

LTV/CAC比率が **4.17**（≥ 3 の目安を超えている）ため、この事業は**健全な水準**にある。顧客獲得コストに対して4倍以上の生涯価値を生み出せている計算となり、マーケティング投資を増やす余地がある状態と判断できる。

**③ LTVを1.5倍（112,500円）にするための施策**

LTV を上げるには「月次収益を増やす」か「チャーン率を下げる」かのいずれかが必要。

**施策1：アップセル・クロスセル施策（月次収益向上）**
現在の月3,000円プランに加え、プレミアムプラン（月5,000円）を設けて機能拡充を提供する。既存ユーザーへの定期的な機能紹介メールでアップグレード率を高め、平均収益単価を引き上げる。

**施策2：解約防止（チャーン率の低下）**
解約率を4%→2.7%程度に下げると LTV は約112,500円まで上昇する（3,000 ÷ 0.027 ≒ 111,000）。解約予兆ユーザー（ログイン頻度低下・機能未活用）へのカスタマーサクセス介入や、長期利用割引（12ヶ月一括払いで2ヶ月分無料など）を導入してロイヤルティを高める。

> **採点ポイント**：LTVの計算が正しいか。LTV/CACの数値と判断が正しいか。LTVを上げる施策が「月次収益増」または「チャーン率低下」のいずれかにつながる具体的な提案になっているかがポイント。
