## レッスン09 模範解答：発想を広げる（ラテラルシンキング / SCAMPER / ブレインストーミング）

---

### 問題1：SCAMPER法の適用（スーパーマーケットのレジ業務）

| 要素 | 問い | アイデア例 |
|---|---|---|
| **S（代替）** | 何かを別のものに置き換えると？ | レジ担当者をセルフレジ機に置き換える。バーコードスキャナーをカメラ認識AIに変える |
| **C（結合）** | 2つのものを組み合わせると？ | 購入履歴と健康管理アプリを連携させ、レジで「今日の栄養バランス」を表示する |
| **A（適応）** | 別の分野のアイデアを適用すると？ | 空港の手荷物検査（X線スキャン）を適用して、カゴごとスキャンで一括自動精算する |
| **M（修正・拡大）** | 大きくする・特性を変えると？ | 自動精算ゾーンを全売り場に広げて「店内をそのまま出るだけで決済完了」にする（Amazon Goモデル） |
| **P（転用）** | 別の用途に使えないか？ | レジ待ち行列を「地域情報の掲示スペース」として活用する。待ち時間にQRコードでクーポンを配布する |
| **E（削除）** | 省いたら？ | レジ会計そのものを省く（入店時にアプリ認証→自動引き落とし）。袋詰め作業を省く（事前に買い物袋を袋型カゴにする） |
| **R（逆転・再配置）** | 逆にする・順番を変えると？ | 先に支払ってから商品を集める（注文→ピッキング→引き渡し、EC的モデルの店内実装） |

**最も実現可能性が高いアイデア：S（代替）「バーコードスキャナーをカメラ認識AIに変える」**

理由：既存のレジ設備を大きく変えずにカメラとAIソフトウェアの追加で実装でき、導入コストが比較的低い。かつ精算速度の向上と人的ミスの削減というニーズに直接応えられる。

> **採点ポイント**：7つの問いすべてにアイデアが記入されているか。アイデアが「現実的かどうか問わず発想を広げる」という趣旨で出されているか。最も実現可能性が高いものの選定に理由があるかがポイント。内容は上記と異なっても、SCAMPER各要素の問いに沿っていれば正答。

### 問題2：逆転発想（オンライン学習サービスのオンボーディング）

**ユーザーが最もこのサービスを嫌いになりすぐ辞めてしまうには？**

1. 最初にやることが多すぎて、どこから始めればいいか全くわからない
2. 進捗が見えず、自分がどれだけ進んでいるか実感できない
3. 学習コンテンツが長くて1コマに1時間以上かかり、隙間時間に使えない
4. 登録直後のメールが毎日大量に届き、全部読む気が失せる
5. アカウント登録後、自分のレベルや目的に合っていないコンテンツを勧められる

**逆転して改善アイデアへ変換**

| 失敗ポイント（逆の問い） | 改善アイデア |
|---|---|
| やることが多すぎる | 初回ログイン時に「まず1つだけやること」を明示するウェルカムフローを設計する（例：最初の1レッスンを5分以内で完了させる） |
| 進捗が見えない | ダッシュボードに学習進捗バー・達成バッジを表示して「続けたくなる仕組み」を作る |
| コンテンツが長い | レッスンを5〜10分の短いチャンクに分割し、通勤・休憩中でも1コマ完結できるようにする |
| メールが多すぎる | 初期設定で通知頻度を「週1回のハイライト」に絞り、ユーザーが自分でカスタマイズできるようにする |
| レベル合わせが悪い | 登録時に目標・経験レベルを入力させ、パーソナライズされた学習ロードマップを提示する |

> **採点ポイント**：逆の問いから「失敗ポイント」を具体的に3〜5つ列挙できているか。各失敗ポイントを「逆転」して改善アイデアとして変換できているかがポイント。「逆転発想」のメカニズム（ネガティブを反転させてポジティブな改善につなげる）が理解されているか確認する。
