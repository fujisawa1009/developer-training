## 電話対応の基本

電話対応は、声だけで相手に印象を与える**会社の顔**となる重要な仕事です。丁寧で的確な対応が、会社の信頼につながります。

### 電話対応が重要な理由

- 電話は**リアルタイムのコミュニケーション**であり、失敗を後から修正できない
- 相手は声のトーン・言葉遣いから担当者（会社）の印象を形成する
- 特にBtoB取引では、電話対応の質が商談に影響することもある

### 電話を受けるとき（受電）

**基本の流れ**

```
1. 2〜3コール以内に出る
2. 「はい、○○株式会社でございます」
3. 相手の会社名・名前を確認する
   「○○様でいらっしゃいますね」
4. 用件を聞く
5. 担当者へ取り次ぐ、または対応する
6. 終話確認・電話を切る（相手が切ってから）
```

**3コール以上鳴らしてしまった場合**

「大変お待たせいたしました、○○株式会社でございます」

**担当者が不在のとき**

```
「申し訳ございません、△△はただいま席を外しております。
よろしければ折り返しのご連絡を差し上げましょうか？
または、ご伝言をお預かりすることもできますが…」
```

### 電話をかけるとき（発信）

**基本の流れ**

```
1. 相手の電話番号・担当者名を確認してから発信
2. 「○○株式会社の△△と申します」
3. 「□□様はいらっしゃいますでしょうか」
4. 用件を簡潔に伝える
5. 確認事項があれば復唱する
6. 「よろしくお願いいたします、失礼いたします」
```

**注意点**

- 始業直後・終業直前・昼休みは避けるのがマナー
- 忙しそうな場合は「今、お時間よろしいでしょうか」と確認
- 要点をまとめてから電話する

### 伝言メモのとり方

電話対応で必ずメモをとる習慣をつけましょう。

**メモの基本項目**

```
日時：○月○日 ○時○分
会社名・お名前：○○株式会社 △△様
連絡先：03-xxxx-xxxx
用件：□□についてのお問い合わせ
対応：折り返し希望 / 伝言のみ
担当：（メモを受けた自分の名前）
```

### よくある電話対応の失敗

| 失敗パターン | 対処法 |
|------------|--------|
| 社名を聞き取れなかった | 「恐れ入りますが、もう一度お社名をお聞かせいただけますか」 |
| 用件がよくわからない | 「確認のため復唱させてください」と整理する |
| 担当者が誰か不明 | 「どのような件でしょうか」と用件から担当を判断する |
| 電話が途切れた | こちらからかけ直す（かけた方がかけ直すのがマナー） |

### 電話のNG表現と正しい表現

| NG | OK |
|----|-----|
| 「ちょっと待ってください」 | 「少々お待ちいただけますでしょうか」 |
| 「わかりません」 | 「確認してご連絡いたします」 |
| 「いません」 | 「席を外しております」 |
| 「○○さんですか？」 | 「○○様でいらっしゃいますか？」 |

> **ポイント：** 電話に出る前に「深呼吸をして笑顔を作る」と、声のトーンが自然と明るくなります。笑顔は声に出ます。

## 練習問題

以下の問いに、自分の言葉で具体的に答えてください。

1. 以下の電話シナリオで、あなたはどのように対応しますか？具体的なセリフを含めて説明してください。
   - **状況：** A株式会社の鈴木様から、担当の田中さん（あなたの先輩）宛に電話がかかってきた。田中さんは外出中で、17時に戻る予定。鈴木様は「今日中に折り返しが欲しい」と言っている。

2. 電話対応において「復唱・確認」が重要な理由を説明し、どのような場面で特に重要か、例を挙げて述べてください。

3. 新入社員が電話対応を苦手とする理由を考え、克服するための具体的な方法を2つ提案してください。
