- [x] 動作確認・モデル設定修正（Claude Haiku 4.5 jp推論プロファイル）

##### 既知の課題（Step 2 で対応）
- 模範解答との差異を確認せずに採点しているため精度が低い
- 期待した解答ではない・解答になっていない回答にも点数がついてしまう

#### Step 2: 模範解答の活用（見積: 2-3日） ✅ 完了
- [x] Assignmentモデルに模範解答フィールド追加（`modelAnswer String?`）
- [x] 管理画面から模範解答を登録できるUIの作成（LessonForm に模範解答欄追加）
- [x] 模範解答のベクトル化・Qdrant保存（`qdrant.ts` 新規作成、課題作成/更新時に自動保存）
- [x] AI採点時の模範解答→プロンプト注入（`executeAiGrading` に注入処理追加）
- [x] 模範解答との差異に基づく採点精度の向上（SYSTEM_PROMPT_BASE に模範解答使用指示追記）
- [x] 課題タイプ `text` をUI（LessonForm）の選択肢に追加（未選択可のままだったバグ修正）
- [x] 採点画面（admin/submissions/[id]）に模範解答の折りたたみ表示を追加
- [x] SQL基礎コンテンツへの模範解答追加（model-answers/01〜18、18ファイル）
- [x] SQL基礎の練習問題コンテンツ追加（assignments/08〜17、10ファイル）
- [x] import.ts を拡張し assignments / model-answers ディレクトリに対応
- [x] 管理者向けレッスン詳細ページ新規作成（`admin/curricula/[id]/lessons/[lessonId]/page.tsx`）

#### Step 3: 過去採点データの蓄積・活用（見積: 2日） ✅ 完了
- [x] 採点完了時のベクトル化・Qdrant保存（`gradeSubmission` fire-and-forget、`grading_examples` コレクション）
- [x] AI採点時の過去事例検索→プロンプト注入（`executeAiGrading` 内で類似事例 Top-3 を取得しプロンプトへ注入）
